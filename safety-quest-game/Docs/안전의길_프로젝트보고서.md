## 1. 프로젝트 개요

### 1.1 프로젝트 목적

**안전의 길**은 현장 안전관리를 자발적으로 모두가 참여하게 하는 게이미피케이션 플랫폼입니다. 중대재해처벌법 대응을 위한 법정 자율점검표 전산화, 역할 기반 워크플로우 자동화, AI 기반 위험도 분석 기능을 제공합니다.

### 1.2 핵심 가치 제안

- **법정 기준 체크리스트 전산화**: 사다리/고소작업대/밀폐공간 표준 템플릿
- **역할 기반 워크플로우 자동화**: 점검→승인→조치 전 과정 자동 기록
- **AI 기반 사진 위험도 분석**: 안전/주의/위험 자동 판별
- **"내 할 일" 중심 실무 UX**: 역할별 우선순위 업무만 노출

### 1.3 주요 사용자 페르소나

| 페르소나 | 역할 | 핵심 Pain | 서비스 가치 |
|----------|------|-----------|-------------|
| **박소장** | 현장 소장 | 점검은 했는데 증명이 안 됨 | 법정 점검표 표준화·전자화 |
| **김대리** | 안전 실무 | 사진·서류·메신저 혼재 | 자동 취합 + 우선순위 정리 |
| **이팀장** | 안전팀장 | 책임소재 입증 부담 | AI 위험도 가시화 + 이력 추적 |

### 3.5 핵심 시스템 구현

#### 3.5.1 레벨 시스템 (15단계)

```
Bronze III (0P) → Bronze II → Bronze I
Silver III → Silver II → Silver I
Gold III → Gold II → Gold I
Platinum III → Platinum II → Platinum I
Diamond III → Diamond II → Diamond I (1,900,000P+)
```

- **설계 기준**: 중간 활동량(150,000P/년) 기준 1년에 1단계 상승
- **구현 파일**: `src/utils/pointsCalculator.js`
- **상세 문서**: `Docs/LEVEL_SYSTEM.md`

#### 3.5.2 아이템 시스템 2.0

**핵심 개념**:

- **안전 스탯(Safety Stats)**: 
  - `pointBoost`: 포인트 획득량 증가 (%)
  - `xpAccelerator`: 경험치 가속 (%)
  - `streakSaver`: 스트릭 보호 (연속 출석 유지)
- **세트 효과**: 동일 세트 아이템 2/4/7피스 장착 시 추가 보너스

**희귀도**:
- Common (기본)
- Rare (희귀)
- Epic (영웅)
- Legendary (전설)

**카테고리**:
- HELMET (안전모)
- VEST (조끼)
- GLOVES (장갑)
- SHOES (안전화)
- BELT (안전띠)
- MASK (마스크)
- GLASSES (보안경)

**구현 파일**:

### 4.3 구현된 도메인 (6개)

#### 4.3.1 Auth 도메인 (인증/인가)

**구현 내용**:
- JWT 기반 인증 시스템
- `AuthController`: 로그인, 토큰 갱신 API
- `AuthService`: 인증 로직
- `JwtTokenProvider`: JWT 토큰 생성/검증
- `JwtAuthenticationFilter`: JWT 인증 필터
- `User`, `Role` 엔티티
- 4개 테스트 계정 생성 (기술인, 감독자, 안전관리자)

**API 엔드포인트**:
- `POST /api/auth/login` - 로그인
- `POST /api/auth/refresh` - 토큰 갱신

**파일 수**: 9개 파일

#### 4.3.2 Template 도메인 (템플릿 관리)

**구현 내용**:
- `TemplateController`: 템플릿 조회 API
- `TemplateService`: 템플릿 비즈니스 로직
