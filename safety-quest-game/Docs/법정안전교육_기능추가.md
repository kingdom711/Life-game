# 법정 안전 교육 기능 추가 문서

## 개요

공모전 기획서의 "10분 마이크로 러닝 기반 스마트 안전 교육" 기능을 프론트엔드에 적용하여 매일 아침 작업 전 10분 내외의 짧은 영상 시청과 퀴즈를 통한 법정 의무 교육 시스템을 구현했습니다.

## 핵심 기능

### 1. 10분 마이크로 러닝
- 매일 아침 작업 전 10분 내외의 짧은 교육 영상 제공
- 한꺼번에 수행하던 교육을 매일 분산하여 학습 부담 감소
- 주차/요일 기반 순환 시스템으로 다양한 교육 콘텐츠 제공

### 2. 이수 자동 인증
- 누적 교육 시간이 법정 의무 시간(연간 4시간) 충족 시 자동 증명서 발급
- 교육 이력 자동 기록 및 관리
- 법정 교육 시간 진행률 실시간 추적

### 3. 실효성 확보
- 영상 시청 후 퀴즈 통과해야 당일 작업 권한 활성화
- 빨리감기 방지로 실제 시청 시간 보장
- 90% 이상 시청 필수, 80점 이상 퀴즈 통과 필수

## 구현 완료 내용

### Phase 1: 데이터 구조 설계 ✅

#### 교육 콘텐츠 데이터 (`src/data/educationData.js`)
- **10개 교육 콘텐츠** 구현 완료
  - 추락 예방: 사다리 작업, 고소작업대, 개구부/단차 추락 예방
  - 끼임/부딪힘: 기계 작업 끼임 예방, 지게차 충돌 예방
  - 개인보호구: 안전모 착용법, 안전대 착용 및 점검
  - 화재/전기: 소화기 사용법, 전기 안전 기본
  - 밀폐공간: 밀폐공간 작업 안전
- **8개 카테고리** 정의
- 각 교육당 **5문제 퀴즈** 포함
- **법정 교육 시간 설정**: 연간 4시간, 분기별 1시간, 월별 최소 0.33시간
- **주차/요일 기반 순환 시스템**: 5주 순환, 월~금요일 배정

#### 스토리지 키 추가 (`src/utils/storage.js`)
- `EDUCATION_PROGRESS`: 현재 진행 중인 교육 상태
- `EDUCATION_HISTORY`: 완료한 교육 이력
- `LEGAL_HOURS`: 누적 법정 교육 시간
- `EDUCATION_QUIZ_ATTEMPTS`: 퀴즈 시도 횟수 (하루 3회 제한)

### Phase 2: 교육 관리 유틸리티 구현 ✅

#### 교육 매니저 (`src/utils/educationManager.js`)
주요 함수:
- `getTodayEducationContent()`: 오늘의 교육 콘텐츠 반환
- `startEducation()`: 교육 시작, 시청 시간 추적
- `updateWatchTime()`: 시청 시간 업데이트 (빨리감기 방지)
- `completeVideo()`: 영상 시청 완료 검증 (90% 이상)
- `submitQuiz()`: 퀴즈 제출 및 채점 (80점 이상 통과)
- `hasCompletedTodayEducation()`: 오늘 교육 완료 여부 확인
- `checkWorkPermission()`: 작업 권한 체크
- `getLegalHoursProgress()`: 법정 교육 시간 진행 상황
- `getEducationStats()`: 교육 통계 조회
- `generateCertificate()`: 이수 증명서 데이터 생성

#### 스토리지 관리 (`src/utils/storage.js`)
- `educationProgress`: 교육 진행 상태 관리
- `educationHistory`: 교육 이력 관리
- `legalHours`: 법정 교육 시간 관리
- `quizAttempts`: 퀴즈 시도 횟수 관리

## 기술적 특징

### 1. 빨리감기 방지
- 이전 최대 시청 위치 추적
- 3초 이상 점프 시 자동으로 이전 위치로 되돌림
- 프로그레스바에서 되감기만 허용

### 2. 시청 시간 검증
- `video.currentTime` 추적
- 로컬 스토리지에 시청 구간 기록
- 최대 시청 시간(`maxWatchedTime`) 관리

### 3. 퀴즈 시도 제한
- 하루 3회 시도 제한
- 시도 횟수 로컬 스토리지에 저장
- 자정 자동 리셋

### 4. 법정 시간 관리
- 연간/분기별/월별 시간 추적
- 진행률 자동 계산
- 증명서 발급 조건 자동 확인
