## 2. 기능별 구현 상세

### 2-1. 보상 공유하기 (기획서 4-5)

**목표**: 레벨업, 레어 아이템 획득, 전직 성공, 월간 개근 달성 시 카카오톡/SNS로 자발적 공유

#### 핵심 구현 내용

- **Web Share API** 기반 공유 (모바일 브라우저 네이티브 공유 UI)
- Web Share API 미지원 환경에서 **클립보드 복사** 자동 폴백
- **Canvas API** 기반 공유 카드 이미지 동적 생성 (600×340px)
- 4가지 공유 유형별 카드 디자인 및 텍스트 템플릿

#### 공유 유형

| 유형 | 트리거 조건 | 카드 텍스트 예시 |
|------|-----------|----------------|
| `levelUp` | 레벨업 달성 | "Silver I 달성! 안전교육 7일 연속 이수" |
| `rareItem` | Epic/Legendary 아이템 구매 | "전설 안전모 획득! 안전 퀘스트 보상" |
| `specialization` | 전직 성공 | "전기 안전 전문가(으)로 전직 성공!" |
| `monthlyAttendance` | 월간 14일+ 출석 보상 수령 | "이번 달 20일 출석 달성! 월간 보상 수령" |

### 2-2. 날씨·계절 연동 안전 팁 (기획서 4-6)

**목표**: 매일 현재 날씨에 맞는 안전 팁을 대시보드에 자동 표시

#### 핵심 구현 내용

- **OpenWeatherMap API** (무료 티어) 연동
- `navigator.geolocation`으로 사용자 위치 자동 감지 (기본값: 서울 37.5665, 126.978)
- **localStorage 캐싱** (1시간 TTL) — API 호출 최소화
- API 실패 시 기존 **정적 팁 로테이션**으로 자동 폴백

#### 날씨-안전 팁 매핑 테이블

| 날씨 조건 | 아이콘 | 안전 팁 |
|----------|:-----:|--------|
| 비 (Rain/Drizzle/Thunderstorm) | 🌧️ | 미끄럼방지 안전화 착용, 작업장 바닥 물기 제거 |
| 눈/한파 (Snow, 기온<0°C) | ❄️ | 보온 장갑 착용, 철골 구조물 결빙 주의 |
| 폭염 (기온≥33°C) | 🔥 | 매 시간 10분 그늘 휴식, 물 충분히 섭취 |
| 강풍 (풍속≥10m/s) | 💨 | 고소작업 중단 검토, 가설구조물 고정 확인 |
| 안개/황사 (Mist/Haze/Dust) | 🌫️ | 방진마스크 착용, 시야 확보 후 중장비 운행 |
| 맑음/기타 | ☀️ | 정적 안전 팁 로테이션 (8종) |

#### 설정

- 환경 변수: `VITE_OPENWEATHER_API_KEY` — `.env` 파일에 OpenWeatherMap API 키 설정 필요
- API 키 미설정 시 정적 팁으로 자동 폴백 (기능 장애 없음)

#### 신규 생성 파일

| 파일 경로 | 역할 |
|----------|------|
| `src/utils/weatherService.js` | OpenWeatherMap API 연동, 날씨-팁 매핑, 캐싱 |

#### 수정 파일

| 파일 경로 | 변경 내용 |
|----------|----------|
| `src/components/dashboard/SafetyTipBar.jsx` | 날씨 데이터 로드 → 아이콘+온도+안전 팁 표시, 폴백 유지 |
| `src/utils/storage.js` | `WEATHER_CACHE` 스토리지 키 추가 |

### 2-3. 사업장 안전 점수 대시보드 (기획서 4-7)

**목표**: 사업장 전체의 안전 수준을 0~100점으로 시각화, 5개 카테고리별 점수 제공

#### 핵심 구현 내용

- **localStorage 기반** 데이터 집계 (서버 불필요)
- 5개 카테고리별 점수 산출 (총 100점 만점)
- SVG 원형 게이지 + 등급 시스템 (A+~F)
- 주간 점수 추이 차트 (최근 4주)
- AI 기반 **개선 제안** (가장 취약한 카테고리 자동 분석)
- **역할 기반 접근 제어**: 관리감독자/안전관리자만 접근 가능

#### 점수 산출 기준

| 카테고리 | 만점 | 데이터 소스 | 산출 기준 |
|---------|:----:|-----------|----------|
| 교육 이수율 | 30점 | `educationHistory` | 최근 7일 중 교육 완료 일수 비율 |
| 퀴즈 평균 점수 | 20점 | `educationHistory.quizScore` | 최근 20건 퀴즈 평균 (80점↑ 만점) |
| 체크리스트 작성률 | 20점 | `safety_quest_checklists` | 최근 7일 중 체크리스트 작성 일수 비율 |
| 위험 발견·해결 | 20점 | `hazardLogs` + `actionRecords` | 최근 7일 활동 건수 (7건↑ 만점) |
| 연속 참여율 | 10점 | `streak` | 연속 참여 일수 (28일↑ 만점) |

#### 등급 체계

| 점수 범위 | 등급 | 라벨 | 색상 |
|:---------:|:----:|:----:|:----:|
| 90~100 | A+ | 매우 우수 | 초록 |
| 80~89 | A | 우수 | 파랑 |
| 70~79 | B | 양호 | 보라 |
| 60~69 | C | 보통 | 노랑 |
| 50~59 | D | 미흡 | 주황 |
| 0~49 | F | 위험 | 빨강 |

#### 신규 생성 파일

| 파일 경로 | 역할 |
|----------|------|
| `src/utils/safetyScoreCalculator.js` | 5개 카테고리 점수 산출, 히스토리 저장, 추이/제안 생성 |
| `src/pages/SafetyScoreDashboard.jsx` | 안전 점수 대시보드 전체 페이지 UI |
| `src/components/dashboard/SafetyScoreWidget.jsx` | 대시보드 홈용 미니 안전 점수 위젯 |

#### 수정 파일

| 파일 경로 | 변경 내용 |

## 4. 기술 스택 및 의존성

### 사용 기술

| 기술 | 용도 | 비고 |
|------|------|------|
| Web Share API | SNS 공유 | 모바일 브라우저 네이티브 지원, 데스크탑 폴백 |
| Canvas API | 공유 카드 이미지 생성 | 600×340px PNG, 외부 라이브러리 불필요 |
| OpenWeatherMap API | 날씨 데이터 조회 | 무료 티어 (1,000회/일) |
| Geolocation API | 사용자 위치 자동 감지 | 기본값 서울 좌표 |
| localStorage | 캐시 및 히스토리 저장 | 기존 프로젝트 패턴 유지 |
| SVG | 원형 게이지 차트 | 외부 차트 라이브러리 불필요 |

### 추가 외부 의존성

없음. 모든 기능이 브라우저 내장 API와 기존 프로젝트 의존성만으로 구현되었습니다.

## 6. 검증 방법

### 날씨·계절 연동 안전 팁

1. `.env` 파일에 `VITE_OPENWEATHER_API_KEY=<API키>` 설정
2. `npm run dev`로 개발 서버 실행
3. 대시보드 상단 SafetyTipBar에 날씨 아이콘·온도·안전 팁 표시 확인
4. API 키 미설정/오프라인 시 정적 팁 로테이션 폴백 확인

### 사업장 안전 점수 대시보드

1. 관리감독자 또는 안전관리자 역할로 로그인
2. 하단 네비게이션에 📊 안전점수 메뉴 확인
3. 대시보드 홈에 미니 안전 점수 위젯 표시 확인
4. 안전점수 페이지에서 5개 카테고리 점수·등급·개선 제안 확인

### 보상 공유하기

1. 상점에서 Epic/Legendary 아이템 구매 → 공유 모달 표시 확인
2. 전직 교육 완료 → 공유하기 버튼 확인
3. 월간 출석 14일+ 보상 수령 → 공유 모달 표시 확인
4. 공유하기 버튼 클릭 → Web Share API 또는 클립보드 복사 동작 확인
