# 안전을 교육으로, 참여로, 생활로 — Safety Quest

### 자발적 교육 참여 기반 소규모 사업장 노동안전 생활화 플랫폼

---

## 1. 한 줄 요약

> **"매일 10분, 스마트폰으로 안전 교육을 받고 퀘스트를 수행하면 포인트와 레벨이 오릅니다. 기술인이 스스로 배우고, 스스로 위험을 찾고, AI의 도움으로 위험을 분석하며, 스스로 해결합니다. 강제가 아닌 자발적 참여로, 교육이 습관이 되고, 습관이 안전 문화가 됩니다."**

### 2-3. 근본 원인 — '아는 것'과 '하는 것'의 간극, 그리고 '타율적 관리'의 한계

작업자들은 안전 수칙을 **모르는 것이 아닙니다**. 알면서도 지키지 않습니다. 더 큰 문제는 안전이 항상 **위에서 내려오는 것**이라는 인식입니다.

```
 현행 안전관리 방식                    결과
┌──────────────┐               ┌──────────────┐
│ 분기 1회      │  ─ 한 번 듣고 → │ 다음 날 66%  │
│ 집합교육      │    잊어버림      │ 망각          │
│ (2~4시간)    │               │ (에빙하우스   │
│              │               │  망각곡선)    │
├──────────────┤               ├──────────────┤
│ 규제·벌칙 중심 │  ─ 감시 없으면 → │ 안전수칙     │
│              │    안 지킴       │ 미준수       │
├──────────────┤               ├──────────────┤
│ 관리자가      │  ─ 작업자는  →   │ 안전은       │
│ 알려주는 위험  │    수동적 수용    │ 남의 일      │
├──────────────┤               ├──────────────┤
│ 일방적 강의   │  ─ 수동적 →     │ 낮은 집중도   │
│              │    참여          │ 형식적 서명   │
└──────────────┘               └──────────────┘
```

**에빙하우스 망각곡선**에 따르면 1회 학습 후 24시간 내 66%, 1개월 후 79%를 잊습니다. 그러나 **간격 반복 학습(Spaced Repetition)**을 적용하면 같은 내용을 주기적으로 반복할 때마다 기억 유지율이 급격히 높아집니다. Safety Quest는 이 원리를 활용합니다.

그리고 무엇보다, **스스로 찾고 스스로 해결한 경험**은 누군가에게 들은 정보보다 **5배 이상 오래 기억됩니다**(자기생성효과, Generation Effect). Safety Quest는 기술인이 위험을 직접 발견하고 AI와 함께 분석하며 해결하는 주체가 되도록 설계합니다.

## 3. 제안 개요 — Safety Quest

### 3-1. 핵심 모티브: 교육과 자발적 참여

Safety Quest의 모든 설계는 두 가지 핵심 모티브에서 출발합니다.

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│   핵심 모티브 1: 교육 (Education)                         │
│   ─────────────────────────────────────────────          │
│   • 매일 10분, 마이크로 러닝으로 실질적으로 배운다           │
│   • AI가 현장 사진을 분석하여 위험을 즉시 교육한다           │
│   • 시나리오 훈련으로 실제 상황 판단력을 기른다              │
│   • 간격 반복으로 한 번 배운 것을 오래 기억한다              │
│   • 학습 경로를 따라 체계적으로 전문성이 쌓인다              │
│                                                          │
│   핵심 모티브 2: 자발적 참여 (Voluntary Participation)    │
│   ─────────────────────────────────────────────          │
│   • 강요가 아닌 보상으로 스스로 참여하게 만든다              │
│   • 경쟁과 성취감이 매일 돌아오게 만드는 동기가 된다          │
│   • 팀·부서 함께 참여하는 사회적 동기를 부여한다             │
│   • 기술인이 안전의 주인공이 되어 능동적으로 행동한다         │
│   • 재미있어서 하다 보면 안전이 일상의 습관이 된다            │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 3-2. 콘셉트

> **기술인이 안전의 주인공이 됩니다.**
> 스스로 배우고, 스스로 위험을 찾고, AI와 함께 분석하며, 스스로 해결합니다.
> 관리자는 감시자가 아닌 **지원자**로서, 기술인의 자율적 안전관리를 돕습니다.
> 벌칙 대신 보상으로, 의무 대신 재미로 안전을 실천하게 만듭니다.

Safety Quest는 네 가지 학술적 원리와 AI 기술을 결합한 **웹 기반(PWA)** 안전교육 플랫폼입니다.

| 원리 | 학술 근거 | Safety Quest 적용 |
|------|----------|-------------------|
| **마이크로 러닝** | 10분 이내 짧은 학습이 기억 정착률 50% 향상 (Journal of Applied Psychology) | 매일 8~10분 영상 + 퀴즈 |
| **간격 반복 학습** | 같은 주제를 5주 주기로 순환하여 장기 기억 전환 | 5주 커리큘럼 순환 (연간 약 10회 반복) |
| **게이미피케이션** | 즉각적 보상이 내적 동기를 형성 (Self-Determination Theory) | 포인트·레벨·아이템·전직·시즌 랭킹 |
| **자기주도 학습** | 능동적 참여가 수동적 수용 대비 기억 정착률 3~5배 향상 (자기생성효과) | 기술인 주도의 위험 발견·AI분석·해결 체계 |
| **AI 보조 분석** | 즉각적 피드백이 학습 효과를 극대화 | GEMS AI가 현장 사진을 실시간 분석·교육 |

### 3-6. 공모전 제안 방향과의 정합성

Safety Quest는 고용노동부가 제시한 **네 가지 아이디어 제안 방향**에 모두 부합합니다.

| 제안 방향 | 핵심 요구 | Safety Quest의 구체적 대응 |
|-----------|----------|--------------------------|
| **패러다임 전환 기여** | 규제 이행에서 자율적 생활 실천으로 바꾸는 아이디어 | 관리자 주도의 하향식 안전관리를 **기술인 주도의 자율적 안전관리**로 전환. 기술인이 스스로 위험을 찾고 AI와 함께 분석·해결하며, 관리자는 이를 **지원**하는 구조. 포인트·레벨·경쟁 보상으로 **자발적 동기**를 부여. 나아가 **작업중지권을 게이미피케이션으로 생활화**하여, 기술인이 위험 시 스스로 작업을 중지할 수 있는 **자율적 안전 권리 행사 문화**를 정착. |

| **문화적 접근** | 시각적 경고보다 인식 개선 콘텐츠, 작업자 행동 유도 중심 아이디어 | "위험합니다!" 경고 대신 "위험을 찾으면 200P + AI 분석!" 형태의 **긍정적 행동 유도**. 전체 역할군의 **경쟁적 해결**로 위험 제거가 게임이자 성취가 됨. |

> **핵심**: Safety Quest는 기술인을 안전관리의 **수동적 대상**에서 **능동적 주체**로 전환합니다. 관리자는 감시자가 아닌 지원자로서, 기술인의 자율적 안전관리를 뒷받침합니다.

### 4-3. GEMS AI — 현장 사진 즉시 분석으로 배우는 AI 교육

#### GEMS(Gemini Enhanced Management System)란

Safety Quest에 탑재된 **AI 위험 분석 엔진**입니다. 기술인이 현장에서 촬영한 사진을 업로드하면, AI가 즉시 위험을 분석하고 조치법을 제안합니다. 단순한 위험 신고가 아닌, **AI가 함께 가르쳐 주는 교육 경험**입니다.

#### 작동 흐름 — 촬영부터 AI 분석까지

```
[1] 현장 사진 촬영       [2] GEMS AI 즉시 분석      [3] 결과 표시 + 교육
                          (Gemini Vision)
┌──────────────┐      ┌──────────────────┐      ┌──────────────────┐
│ 📸 카메라로   │      │ 안전 지능 시스템이 │      │ ⚠️ 위험도: 높음   │
│  위험 상황    │  →   │  분석 중입니다...  │  →   │                  │
│  촬영        │      │                  │      │ 위험 유형: 추락    │
│              │      │  (AI 스캔 중)     │      │ 원인: 사다리 고정  │
│              │      │                  │      │ 핀 미체결          │
└──────────────┘      └──────────────────┘      │                  │
                                                 │ 조치 방법:         │
                                                 │ 1. 즉시 작업 중단  │
                                                 │ 2. 고정핀 교체     │
                                                 │ 3. 재확인 후 재개  │
                                                 │                  │
                                                 │ [등록] [작업중지]  │
                                                 └──────────────────┘
```

#### GEMS가 제공하는 교육 효과

| 기존 방식 | GEMS AI 방식 |
|----------|-------------|

### 4-4. 위험 사이클 시스템 — 발견부터 해결까지 완전한 추적

#### 왜 '사이클'인가

기존 위험 신고 시스템은 **신고 후 어떻게 됐는지 알 수 없습니다**. Safety Quest의 위험 사이클 시스템은 위험의 **발견(Before) → AI분석 → 등록 → 해결 → 완료사진(After) → 공유**까지 전 과정을 하나의 사이클로 추적합니다.

#### 위험 사이클 5단계

```
┌─ STAGE 1: 발견 ──────────────────────────────────────────┐
│  기술인이 현장에서 위험 발견 → 스마트폰으로 사진 촬영       │
│  → 위험 내용 서술 → GEMS AI 분석 요청                      │
└─────────────────────────────────────────────────────────┘
                          ↓ 200P 획득
┌─ STAGE 2: AI 분석 ───────────────────────────────────────┐
│  GEMS AI: 위험도 판정 + 원인 분석 + 조치법 제안            │
│  → 전체 대시보드에 AI 분석 결과와 함께 노출                 │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─ STAGE 3: 경쟁 해결 ─────────────────────────────────────┐
│  누구든 먼저 해결 가능 (기술인 300P / 관리감독자 250P)      │
│  AI가 제안한 조치법을 참고하여 실제 해결                    │
└─────────────────────────────────────────────────────────┘
                          ↓ 300P 획득
┌─ STAGE 4: 완료 등록 ─────────────────────────────────────┐
│  해결 완료 후 "완료 사진" 등록                              │
│  조치 내용 서술 필수 → 실질적 위험 제거 보장                │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─ STAGE 5: Before/After 비교 공유 ────────────────────────┐
│  발견 전 사진 ←→ 해결 후 사진 자동 비교                     │
│  "이 위험이 이렇게 해결됐습니다" — 전체 공유                 │
│  → 다른 기술인의 학습 자료가 됨                             │
└─────────────────────────────────────────────────────────┘
```

완결된 위험 사이클은 **위험 사이클 이력**으로 보관됩니다. Before/After 사진과 AI 분석 결과, 조치 내용이 모두 기록되어 기술인의 성과 확인, 관리자의 패턴 파악, 사업주의 개선 이력 확보에 활용됩니다.

```
┌─ 사업장 위험 히트맵 ──────────────────────────────────────┐
```

> **핵심**: 자동 발송이 아닌 **기술인 본인이 누르는 공유 버튼**. 강제가 아닌 **자발적 자랑**.

### 4-11. 작업중지권 생활화 시스템 — 위험하면 멈출 수 있는 용기

#### 왜 '작업중지권'인가

산업안전보건법 제52조는 근로자에게 **작업중지권**을 보장합니다. 2025년 고용노동부 '노동안전 종합대책'에서 이 권리가 대폭 강화되었습니다.

| 항목 | 기존 | 2025년 확대 |
|------|------|-----------|
| **행사 기준** | "급박한 위험" 시 | **"발생 우려"** 시로 완화 |
| **보복 제재** | 행정 제재 | **형사처벌** 도입 |
| **행사 주체** | 근로자 개인 | **노동조합**도 주체 가능 |
| **요청 제도** | 없음 | 근로자가 사업주에게 **작업중지 요청** 가능 |

#### (1) 작업중지권 교육 모듈 + 시나리오 훈련

기존 5주 순환 커리큘럼에 **작업중지권 전용 교육 모듈**과 **시나리오 기반 상황 판단 퀴즈**를 추가합니다.

| # | 시나리오 | 정답 |
|:-:|---------|:----:|
| 1 | 고소작업 중 비계 연결부 볼트가 풀려 있는 것을 발견. 관리감독자가 현장에 없음. | **작업 중지 + 대피 + 신고** |
| 2 | 밀폐공간 작업 전 가스 측정기 경고등 작동. 관리감독자가 "괜찮으니 들어가라" 지시. | **작업중지권 행사 (지시 거부 가능)** |
| 3 | 작업중지 행사 후 관리감독자가 "다음부터 이러면 불이익" 발언. | **불법 보복 — 형사처벌 대상** |

> **연간 반복 효과**: 작업중지권 모듈을 **연간 약 30회** 반복 학습. 권리가 일상으로 체화됩니다.

#### (2) 긴급 작업중지 버튼 — 위험할 때 1터치로 행사

```
[1] 버튼 터치            [2] 확인 + 유형 선택         [3] 즉시 전파
                         (오터치 방지)

┌──────────────┐      ┌──────────────────┐      ┌──────────────────┐
│  ✋ 터치     │  →   │ ⚠️ 작업중지를      │  →   │ ✅ 전파 완료      │
│              │      │ 행사하시겠습니까?  │      │ • 전체 알림 발송   │
│              │      │ ○ 추락 위험      │      │ • 관리감독자 통보  │
│              │      │ ○ 끼임 위험      │      │ • 타임스탬프 기록  │
│              │      │ [행사] [취소]     │      │ [사진 추가]       │
└──────────────┘      └──────────────────┘      └──────────────────┘
```

오프라인 상태에서도 기록이 저장되고, 인터넷 연결 후 자동 동기화됩니다. **작업중지 이력**은 별도 메뉴에서 조회 가능하며 법적 증거로 활용됩니다.

#### (3) "멈추는 것이 영웅이다" — 보상 체계

```
  일반 위험 발견·등록            작업중지 행사 (검증 완료)
  ┌──────────────┐            ┌──────────────────────┐
  │   200P       │            │   500P (2.5배!)       │
```

### 5-2. 사업장 규모별 도입 시나리오

#### 시나리오 A: 1~5인 인테리어 시공업체

- **효과**: 1인 사업장에서도 **기술인 스스로 안전을 관리**. 법정 교육시간 자동 충족.

#### 시나리오 B: 10~20인 건설 현장

- **기술인**: 매일 10분 교육 + **현장 위험 발견 → AI 분석 → 등록** + 직접 해결
- **현장소장**: 기술인이 지원 요청한 건에 대해 **해결 지원**
- **부서 대항전 + 시즌 랭킹**: 기술인 간 경쟁 → 안전 참여 활성화

#### 시나리오 C: 30~50인 제조 공장

- **기술인**: 위험 발견·AI분석·등록·직접 해결
- **관리감독자**: 지원 요청 위험 해결 지원
- **안전관리자**: 전문 조치 + 재발방지 대책 + 히트맵으로 위험 집중 구역 모니터링

### 6-2. 기대 효과 — 세 가지 차원

#### 1차 효과: 기술인의 자율적 행동 변화

| 변화 전 | 변화 후 | 동인 |
|--------|--------|------|
| "안전교육? 서명만 하면 되지" | 매일 10분 **자발적 참여** | 포인트·레벨 보상 |
| "안전수칙? 알긴 아는데..." | 매일 반복으로 **체화된 습관** | 간격 반복 학습 |
| "위험? 누군가 알려주겠지" | **내가 직접 찾고 AI와 분석**한다 | GEMS AI + 위험 발견·해결 보상 |
| "보호구? 불편해서 안 써" | 게임 아이템으로 **친숙함과 애착** 형성 | 수집·강화·단조 동기 |
| "안전은 관리자 몫이지" | **안전은 내가 만드는 것** | 자기주도 + 성취감 |

#### 2차 효과: 조직 문화 변화

- **기술인 주도의 안전 문화**: "위에서 시켜서"가 아닌 "**내가 알아서**" 하는 문화
- **관리자의 역할 전환**: 감시자에서 **지원자**로 → 기술인과의 신뢰 관계 강화
- **경쟁을 통한 협력**: 부서 대항전·시즌 랭킹이 결과적으로 **사업장 전체의 안전 수준 향상**으로 연결
- **데이터 기반 의사결정**: 히트맵·준수 보고서·안전 점수로 **객관적 안전 현황 파악**

#### 3차 효과: 사고 예방 기여

- 기술인이 **직접 위험을 발견**하고 **GEMS AI와 함께 분석**하므로 → 발견 건수 및 정확도 향상
- **경쟁적 해결 구도**로 → 발견된 위험의 **신속한 해결**
- 매일 **50가지 핵심 위험 시나리오** 반복 훈련 → 위험 인지 능력 향상
- **히트맵**으로 위험 집중 구역 파악 → 예방적 환경 개선
