# 안전의 길 UI 디자인 시스템

2026-10-06 개정. 제품 모토는 **안전을 게임으로. 오늘의 현장이, 나의 성장으로.**
화면은 가볍고 읽기 쉽게 유지하면서 캐릭터, 퀘스트, 경험치, 가상 장비로 안전 활동의 성장을 보여준다.

## 공통 스타일

최종 테마는 `src/styles/pages/adventure.css`이며, 기존 스타일 다음에 불러온다.
신규 화면은 의미에 맞는 변수를 사용한다. 고정된 다크 모드 색상이나 배경 장식은 추가하지 않는다.

| 용도 | 변수 | 색상 |
|---|---|---|
| 바탕 | `--adventure-bg` | #f7f5ee |
| 카드 | `--adventure-paper` | #ffffff |
| 본문 | `--adventure-ink` / `--color-text` | #242636 |
| 보조 문구 | `--adventure-muted` | #626477 |
| 주 행동·경험치 | `--adventure-primary` | #5456b8 |
| 버튼 하단 | `--adventure-primary-dark` | #3e4091 |
| 보조 강조 | `--adventure-soft` | #ededfb |
| 보상 배경·장식 | `--adventure-gold` | #f2ca62 |
| 보상 텍스트 | `--adventure-gold-ink` | #755019 |
| 테두리 | `--adventure-line` | #dedee8 |
| 위험 | `--color-danger` | #b93e35 |
| 완료·안전 | `--color-safe` | #237354 |

기존 `--color-*`, `--glass-*` 변수를 같은 표면과 색상에 연결한다. 색상 변수에 `20` 등의 문자열을 붙여 투명도를 만들지 않는다. 필요하면 `color-mix()`를 사용한다.
버튼은 보통 44px 이상, 주 퀘스트 버튼은 48px 이상 높이를 확보한다. 키보드 포커스를 표시하고 진행 상태를 글자와 아이콘으로 함께 설명한다.
유리 효과, 전체 배경 영상, 네온 그림자, 반복적인 배경 애니메이션보다 콘텐츠의 순서를 우선한다. 퀴즈의 정오답 피드백 등 의미 있는 게임 반응은 유지한다.

## 홈 구성

1. 브랜드와 모토, 실제 출석 기록, 알림·작업중지 진입.
2. 역할 캐릭터, 이름, 현장·팀, 현재 레벨과 다음 레벨까지 남은 XP.
3. 출석·교육·역할별 퀘스트 경로와 지금 도전할 퀘스트 하나.
4. 위험 발견과 현장 시나리오 진입, 추가 도전은 펼침 영역.
5. 실제 포인트·완료 수·장착 장비·최근 보상·팀 참여 기록.

모바일은 한 열, 768px 이상 홈은 본문과 320px 보조 열로 구성한다. 전체 컨테이너는 최대 1120px이다. 프로필은 최대 860px, 교육 콘텐츠는 최대 760px이다.

## 게임 상태와 실제 데이터

`TodayMissions`는 기존 `isActive`, `isLocked`, `isCompleted`를 표시하고 기존 동작 처리 함수에 퀘스트를 전달한다. 경로의 순서는 안내용이며 출석을 선행 조건으로 추가하지 않는다. 필수 교육을 마치면 기존 규칙에 따라 나머지 도전이 열린다. 완료된 퀘스트를 다시 눌러 보상을 받게 만들지 않는다.

현재 XP는 `level.get()`의 `current`, `exp`, `expToNext`를 사용한다. 포인트 등급과 경험치 레벨을 구분한다.
역할 캐릭터는 기존 이미지 에셋을 사용한다. 장비 이미지는 불투명한 제품 그림이므로 캐릭터 옆의 썸네일과 희귀도 테두리로 표현한다. 실제 보호구 착용 확인을 뜻하지 않는다.
참여자 수, 안전 점수, 순위, 날씨, 팀 진행률, 보상 기록을 임의로 채우지 않는다. 데이터가 없으면 빈 상태나 미집계 상태를 표시한다.

## 메뉴·인증·베타 운영

기본 하단 메뉴는 모험·캐릭터·우리 팀·전체이다. 전체 메뉴는 네이티브 대화상자로 열며 키보드와 닫기 버튼을 지원한다. 관리자 메뉴는 기존 권한 플래그에 따른다.
베타 종료 시 참여자 메뉴는 기존 내 점수·보상안내·게시판만 표시한다. 종료 플래그, 인증, 서버 권한, 교육 판정, 포인트 계산, 직접 지급 방식은 디자인 변경 대상이 아니다.

## 검토와 복원

`scripts/ui-review.html`은 개발 전용 구성요소 검토 화면이다. 예시 데이터임을 표시하고 상태 전환은 메모리에만 남긴다. 실제 계정으로 로그인하거나 보상을 지급하지 않는다. 기본 제품 빌드에 포함되지 않는다.
이번 변경 내용, 검증 범위와 복원 방법은 저장소 루트의 `Docs/UI_SAFETY_ADVENTURE_CHANGELOG_2026-10-06.md`에 기록한다. 이전 디자인 문서는 수정 전 백업 압축 파일에 보존되어 있다.
