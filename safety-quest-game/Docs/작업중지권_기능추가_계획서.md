# 작업중지권 기능 추가 계획서

## Safety Quest — 작업중지권 생활화 시스템

---

## 1. 배경 및 필요성

### 1-1. 작업중지권이란

**작업중지권**은 산업안전보건법 제52조에 근거한 근로자의 법적 권리로, 산업재해가 발생할 **급박한 위험**이 있을 때 작업을 중지하고 대피할 수 있는 권리입니다.

### 1-2. 2025년 노동안전 종합대책 — 작업중지권 확대

고용노동부 '노동안전 종합대책'(2025.9)에서 작업중지권이 대폭 강화되었습니다.

| 항목 | 기존 | 2025년 확대 |
|------|------|-----------|
| **행사 기준** | "급박한 위험" 시 | **"발생 우려"** 시로 완화 |
| **보복 제재** | 행정 제재 | **형사처벌** 도입 |
| **행사 주체** | 근로자 개인 | **노동조합**도 주체 가능 |
| **요청 제도** | 없음 | 근로자가 사업주에게 **작업중지 요청** 가능 |
| **정부 권한** | 제한적 | 고용노동부 장관의 **작업중지 명령권** 강화 |

### 1-3. 소규모 사업장의 작업중지권 문제

| 문제 | 원인 | Safety Quest의 해결 방향 |
|------|------|------------------------|
| 작업중지권 인지 부재 | 별도 교육 없음 | **매일 반복 교육**으로 권리 인식 정착 |
| 행사 두려움 | 보복·해고 우려 | **익명 신고** + **보복 모니터링** |
| 행사 방법 모름 | 절차 교육 없음 | **시나리오 훈련**으로 행사 절차 체화 |
| 기록 부재 | 문서화 시스템 없음 | **앱 내 자동 기록** + 증거 보존 |
| 심리적 장벽 | "일 방해한다"는 인식 | **게이미피케이션**으로 "영웅적 행동" 프레이밍 |

### 1-4. Safety Quest와의 정합성

Safety Quest의 핵심 철학 **"기술인이 스스로 찾고, 스스로 해결한다"**는 작업중지권의 본질과 완벽히 일치합니다.

```
 기존 안전관리                          Safety Quest + 작업중지권
┌──────────────────┐              ┌──────────────────┐
│                  │              │                  │
│  위험해도 참고    │              │  위험하면 스스로   │
│  작업 계속       │              │  작업을 중지      │
│       ↓          │              │       ↓          │
│  사고 발생       │              │  위험 기록·신고    │
│       ↓          │              │       ↓          │
│  사후 처리       │              │  보상 획득 +      │
│                  │              │  위험 해결        │
│  결과: 사고는     │              │       ↓          │
│  어쩔 수 없는 것  │              │  결과: 사고 예방   │
│                  │              │  + 안전 문화 정착  │
└──────────────────┘              └──────────────────┘
```

## 2. 추가 기능 상세 — 6가지 핵심 기능

### 2-1. 작업중지권 교육 모듈

#### 왜 '작업중지권 교육'인가

소규모 사업장 근로자의 대다수는 작업중지권의 존재 자체를 모릅니다. 알더라도 "행사하면 잘린다"는 두려움이 큽니다. Safety Quest의 **마이크로 러닝 + 간격 반복** 체계에 작업중지권 교육을 통합하면, 근로자가 이 권리를 **자연스럽게 인지하고 체화**할 수 있습니다.

#### 교육 모듈 구성 (기존 5주 커리큘럼에 추가)

| 주차 | 요일 | 교육 모듈 | 핵심 학습 내용 |
|:----:|:----:|----------|-------------|
| 추가1 | 수 | **작업중지권이란 무엇인가** | 산업안전보건법 제52조, 2025년 확대 기준 ("발생 우려"), 행사 가능 상황 예시 |
| 추가2 | 수 | **작업중지권 행사 5단계** | ① 위험 인지 → ② 작업 중지 → ③ 대피 → ④ 신고 → ⑤ 기록 |
| 추가3 | 수 | **보복 금지와 나의 보호** | 보복 시 형사처벌, 불이익 발생 시 대응법, 익명 신고 방법 |

#### 시나리오 기반 퀴즈 예시

**예시 1: 사다리 작업 중 상황 판단**

| # | 시나리오 | 선택지 | 정답 |
|:-:|---------|--------|:----:|
| 1 | 고소작업 중 비계 연결부 볼트가 풀려 있는 것을 발견했습니다. 관리감독자가 현장에 없습니다. | A) 볼트를 직접 조이고 작업 계속 / B) 작업을 중지하고 대피 후 신고 / C) 동료에게 알리고 작업 계속 | **B** |
| 2 | 밀폐공간 작업 전 가스 측정기 경고등이 깜빡입니다. 관리감독자가 "괜찮으니 들어가라"고 합니다. | A) 관리감독자 지시를 따른다 / B) 작업중지권을 행사하고 대피한다 / C) 잠시 기다렸다 들어간다 | **B** |
| 3 | 작업중지권을 행사한 후 관리감독자가 "다음부터 이러면 불이익이 있을 것"이라고 합니다. 이는? | A) 정당한 관리 행위 / B) 불법 보복으로 형사처벌 대상 / C) 구두 경고일 뿐 문제없음 | **B** |

#### 기존 시스템 연동

```
기존 마이크로 러닝 체계              작업중지권 교육 추가
┌────────────────────┐          ┌────────────────────┐
│ 10분 영상 시청      │          │ 10분 영상 시청      │
│ + 빨리감기 차단     │    →     │ (작업중지권 내용)    │
│ + 퀴즈 5문항 80%   │          │ + 시나리오 판단 퀴즈  │
│ + 교육 미완료 시    │          │ + 법정 교육시간 누적  │
│   퀘스트 잠금       │          │ + 간격 반복 순환     │
└────────────────────┘          └────────────────────┘
```

> **연간 반복 효과**: 3개 모듈 × 약 10순환 = 작업중지권을 **연간 약 30회** 반복 학습

### 2-2. 긴급 작업중지 버튼

#### 왜 '긴급 버튼'인가

실제 위험 상황에서 메뉴를 찾아 들어갈 시간이 없습니다. 2025년 확대된 기준("발생 우려")에 따라 위험이 감지되면 **즉시 행사**할 수 있어야 합니다.

#### 작동 방식

```
┌─ 대시보드 화면 ─────────────────────────────────────────────────────┐
│                                                                     │
│  [일반 메뉴들...]                                                    │
│                                                                     │
│                                                    ┌──────────────┐ │
│                                                    │              │ │
│                                                    │  ✋ 작업중지  │ │
│                                                    │  (빨간 버튼)  │ │
│                                                    │              │ │
│                                                    └──────────────┘ │
│                                          ▲ 항상 보이는 플로팅 버튼    │
└─────────────────────────────────────────────────────────────────────┘

[1] 버튼 터치           [2] 확인 다이얼로그        [3] 즉시 전파
                        (오터치 방지)

┌──────────────┐     ┌──────────────────┐     ┌──────────────────────┐
│              │     │ ⚠️ 작업중지를      │     │ ✅ 작업중지가         │
│  ✋ 터치     │ →   │ 행사하시겠습니까?  │ →   │    전파되었습니다      │
│              │     │                  │     │                      │
│              │     │ 위험 유형 선택:   │     │ • 전체 알림 발송 완료  │
│              │     │ ○ 추락 위험      │     │ • 관리감독자 통보 완료 │
│              │     │ ○ 끼임 위험      │     │ • 안전관리자 통보 완료 │
│              │     │ ○ 전기 위험      │     │                      │
│              │     │ ○ 기타          │     │ [사진 추가] [상세 기록]│
│              │     │                  │     │                      │
│              │     │ [행사] [취소]     │     │ 타임스탬프: 자동 기록  │
└──────────────┘     └──────────────────┘     └──────────────────────┘
```

#### 핵심 설계 원칙

| 원칙 | 설명 |
|------|------|
| **1터치 접근** | 어떤 화면에서든 1번의 터치로 접근 가능 |
| **오터치 방지** | 확인 다이얼로그로 실수 방지 (하지만 2단계 이하로 제한) |
| **오프라인 지원** | 인터넷 미연결 시에도 기록 저장 → 연결 후 자동 동기화 |
| **즉시 전파** | 행사 즉시 모든 역할군에 실시간 알림 발송 |
| **증거 보존** | 타임스탬프·위치·사용자 자동 기록 → 법적 증거 확보 |

### 2-3. 작업중지 신고·기록 시스템

#### 왜 '신고·기록'인가

작업중지권을 행사해도 **기록이 없으면 법적 보호를 받기 어렵습니다**. 소규모 사업장에는 이를 체계적으로 기록할 시스템이 없습니다. Safety Quest가 이 역할을 합니다.

#### 작동 흐름 — 신고에서 작업재개까지

```
┌─ STEP 1: 기술인이 작업중지 행사 ────────────────────────────────────┐
│                                                                     │
│  위험 상황 발생 → 작업 중지 → 대피 → 앱으로 신고                     │
│                                                                     │
│  ▸ 위험 유형 선택 (추락·끼임·부딪힘·전기·화재·밀폐·기타)              │
│  ▸ 사진 촬영 (증거 확보)                                             │
│  ▸ 상황 서술 (음성 또는 텍스트)                                       │
│  ▸ 위치 표시 (현장 구역 선택)                                         │
│  ▸ 익명/실명 선택 가능                                               │

                                    ↓
┌─ STEP 2: 전체 대시보드에 즉시 노출 ─────────────────────────────────┐
│                                                                     │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐             │
│  │ 기술인       │    │ 관리감독자   │    │ 안전관리자   │             │
│  │ 대시보드     │    │ 대시보드     │    │ 대시보드     │             │
│  │             │    │             │    │             │             │
│  │ ✋ 작업중지! │    │ ✋ 작업중지! │    │ ✋ 작업중지! │             │

│  [신고] → [접수확인] → [조사 중] → [위험 해결] → [작업 재개]         │

#### 익명 신고 — 소규모 사업장의 현실적 해법

※ 3인 사업장에서 "익명 신고 1건"은 사실상 신고자를 특정할 수 있음
   → 시스템이 신고 시점을 분산 표시하여 특정 방지
```

> **핵심**: 2025년 정책에서 근로자가 사업주에게 작업중지를 **"요청"**할 수 있도록 제도가 신설되었습니다. 익명 요청은 이 제도를 소규모 사업장에서 실질적으로 작동시키는 핵심 장치입니다.

### 2-4. 작업중지권 퀘스트·보상 체계

#### 왜 '보상'인가

작업중지는 현장에서 **부정적 행동**으로 인식됩니다. "일을 세운 사람"이라는 낙인이 찍힙니다. Safety Quest는 이를 **"현장을 지킨 영웅"**으로 전환합니다.

#### 기술인 — 작업중지권 관련 퀘스트

| 퀘스트명 | 수행 내용 | 보상 | 소요 시간 |
|---------|----------|:----:|:---------:|
| 오늘의 안전 권리 | 작업중지권 관련 법률 팁 1건 읽고 확인 | 30P | 1분 |
| 안전 판단 훈련 | 시나리오 기반 작업중지 판단 퀴즈 1건 | 50P | 2분 |
| 용기 있는 행동 | 위험 상황 작업중지 행사·신고 (검증 후) | **500P** | 수시 |
| 안전 판단 마스터 (주간) | 주간 시나리오 퀴즈 3건 통과 | 500P | — |
| 안전 수호자 (월간) | 월간 작업중지권 교육 전체 이수 | 3,000P | — |

#### 관리감독자 — 작업중지 대응 퀘스트

| 퀘스트명 | 수행 내용 | 보상 | 소요 시간 |
|---------|----------|:----:|:---------:|
| 신속 대응자 | 작업중지 신고 30분 내 접수확인 | 200P | 수시 |
| 안전 해결사 | 작업중지 위험요인 해결·작업재개 승인 | 300P | 수시 |
| 격려 한마디 | 작업중지 행사 기술인에게 긍정 피드백 | 50P | 1분 |

#### "용기 포인트" — 작업중지 보상이 위험 발견보다 높은 이유

```
  일반 위험 발견·등록           작업중지 행사 (검증 완료)
  ┌──────────────┐           ┌──────────────────────┐
  │   200P       │           │   500P (2.5배!)       │
  │              │           │                      │
  │ 위험을 발견해서│           │ 위험을 발견하고        │
  │ 등록함        │           │ 용기 있게 작업을       │
  │              │           │ 중지한 행동에 대한     │
  │              │           │ 더 큰 보상            │
  └──────────────┘           └──────────────────────┘

  → 작업중지 = 더 높은 보상 = "영웅적 행동"이라는 메시지
```

> **설계 의도**: 위험 발견(200P)보다 작업중지 행사(500P)에 더 높은 보상을 부여하여, **"작업을 세운다 = 가장 용감하고 가치 있는 행동"**이라는 인식을 형성합니다.

### 2-5. 안전 수호자 전직 경로
