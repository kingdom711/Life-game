# 전직센터 신규 역할 추가 구현 플랜: 화재감시자, 안전담당자

## 개요
전직센터에 기존 3개 역할(유도원, 신호수, 밀폐담당자)과 동일한 UI/버튼 구성으로 **화재감시자**와 **안전담당자** 2개 역할을 추가한다.
교육 콘텐츠(YouTube ID, 퀴즈)는 사용자가 별도 제공 예정이므로 placeholder로 구성한다.

## 핵심 설계
시스템이 데이터 기반(data-driven)으로 구현되어 있어 `SPECIALIZATIONS` 배열과 `specializationEducations` 배열에 항목만 추가하면 UI/비즈니스 로직이 자동 적용된다.
`specializationManager.js`, `SpecializationTrainingPage.jsx`, `storage.js`, `App.jsx` 라우팅 등은 수정 불필요.

## 신규 역할 스펙

| 항목 | 화재감시자 | 안전담당자 |
|------|----------|----------|
| ID | `fireWatcher` | `safetyOfficer` |
| 아이콘 | 🔥 | ⛑️ |
| 색상 | `#f97316` (orange) | `#14b8a6` (teal) |
| 그라데이션 | `linear-gradient(135deg, #f97316, #ea580c)` | `linear-gradient(135deg, #14b8a6, #0d9488)` |
| 해금 레벨 | 6 (Silver I) | 7 (Gold III) |
| 포인트 배율 | 1.3x | 1.35x |
| 전직 보상 | 1500P / 250 EXP | 2000P / 300 EXP |
| 교육 수 | 2개 | 3개 |

## 검증 방법

1. `npm run dev` 실행 후 브라우저에서 전직센터 페이지 접속
2. 5개 전직 카드가 반응형 그리드에 정상 표시되는지 확인
3. 화재감시자/안전담당자 카드 클릭 시 교육 목록(placeholder) 표시 확인
4. 교육 상세 진입 시 빈 YouTube ID로 fallback UI 정상 표시 확인
5. placeholder 퀴즈 제출 → 점수 산정 → 이수 처리 흐름 확인
