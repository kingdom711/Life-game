# YouTube 전직센터 교육 영상 통합 구현 플랜

## 개요
전직센터의 **유도원, 신호수, 밀폐담당자, 화재감시자, 안전담당자** 교육을 활성화하기 위해 법정 교육시간 기준을 충족하는 신빙성 있는 안전보건공단 등의 유튜브 교육 자료를 연동합니다. 기존 시스템의 기능을 확장하여 빨리감기/넘기기를 방지하고, 다수의 영상으로 구성된 커리큘럼의 실제 시청 시간이 경과해야만 퀴즈 및 이수 처리가 가능하도록 기능을 구현합니다.

## 주요 요구사항
1. **YouTube 영상 연결** - 신빙성 있는 정부/공공기관(안전보건공단 등)의 영상 URL 지원
2. **법정 교육시간 충족 (재생목록 지원)** - 단편 영상을 묶어 법정 교육시간(예: 2시간, 4시간 등)을 구성할 수 있도록 재생목록 형태 지원
3. **빨리감기/넘기기 방지** - 학습자가 영상을 건너뛸 수 없도록 강제
4. **실제 누적 시청 시간 추적** - 일시정지나 탭 이탈 시 시간 카운트 중단 및 다중 영상 누적 시간 체크
5. **조건부 이수 및 퀴즈 활성화** - 필수 법정 코스 시청 시간 충족 및 전체 목록 이수 후에만 "문제 풀기" 및 "이수 완료" 버튼 표시

---

## User Review Required

> [!IMPORTANT]
> **재생목록(Playlist) 구성 여부**: 유튜브 단일 영상만으로는 법정 교육시간(2시간 이상)을 채우기 어렵습니다. 여러 영상을 순차적으로 재생하고 관리하는 재생목록 UI 및 전체 진행률 구현이 추가로 필요합니다.
> **평가(퀴즈) 시간 포함**: 실제 법정 교육을 유튜브로 완전 갈음할 경우, 영상 시청 시간과 더불어 평가(퀴즈) 푸는 시간을 교육 시간에 포함할지 결정 및 로직 반영이 필요합니다.

> [!WARNING]
> **YouTube Player 제약사항**: YouTube는 기본적으로 사용자에게 재생 바를 제공합니다. JavaScript로 seek 이벤트를 감지해 되돌릴 수는 있으나 모바일 등 특수 환경에서는 제어가 완벽하지 않을 수 있으므로 UI 적으로 제어바를 가리는 꼼꼼한 처리가 권장됩니다.

## Proposed Changes

### 1. 전직센터 비디오 플레이어 컴포넌트 확장

#### [NEW/MODIFY] `JobCenterEducationPlayer.jsx` (또는 기존 `YouTubeEducationPlayer.jsx` 확장)

연속 재생(재생목록) 및 코스별 누적 시간 관리를 지원하도록 컴포넌트 확장:

```javascript
// 핵심 기능
- 단일 영상이 아닌 다중 영상(Playlist) 순차 재생 지원
- 영상별 시청 완료 상태 및 총 누적 시청 시간(Total Watch Time) 관리
- Seek 감지 및 되돌리기 (빨리감기 원천 차단)
- 모듈별(신호수, 밀폐담당자 등) 법정 이수 시간 체크 로직
```

**새로운 Props 파라미터 제안:**
- `playlistVideos`: 재생할 YouTube 비디오 ID와 메타데이터 배열
- `totalRequiredWatchTime`: 코스 전체 필수 시청 시간 (초)
- `currentVideoIndex`: 현재 재생 중인 연속 영상의 인덱스 상태

## 퀴즈 연동 수정 방향
- 단일 영상별 5지선다 퀴즈 포맷을 확장하여, 직무별(신호수/밀폐담당/화재감시자/안전담당자) 커리큘럼 내 전체 재생목록 이수 완료 시 종합 평가(전체 10~20문항 무작위 출제) 형태로 퀴즈 모달을 통합 개편합니다.
- 평가 통과 기준(예: 80점 이상) 만족 시 전직센터 교육 이력에 수료로 서버에 처리되도록 연계합니다.
