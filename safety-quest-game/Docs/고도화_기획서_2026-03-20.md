## 1. 고도화 배경 및 목표

### 1-1. 현재 상태 요약

Safety Quest는 다음 핵심 기능을 구현 완료한 상태입니다.

| 영역 | 구현 완료 기능 |
|------|--------------|
| 인증/권한 | JWT 인증, 4단계 RBAC (WORKER → ADMIN) |
| 게이미피케이션 | 퀘스트(일/주/월), 레벨·경험치, 듀얼 화폐, 장비·인벤토리, 전직, 랭킹 |
| 안전 관리 | 체크리스트, 위험 신고, 작업중지권, 알림, 교육(YouTube) |
| AI | Gemini 기반 사진 분석·위험 탐지 |
| 인프라 | PWA, 오프라인 지원, 서버↔클라이언트 동기화 |

## 3. Phase 1 — 즉시 착수 가능 기능 (기존 코드 위에 구축)

### 3-1. 업적(Achievement) 시스템

**목표**: 장기 목표 제시를 통한 지속적 참여 동기 부여

#### 기능 설명

퀘스트가 "오늘 할 일"이라면, 업적은 "장기적으로 달성할 목표"입니다. 특정 조건 달성 시 뱃지를 수여하고, 뱃지는 프로필에 영구 표시됩니다.

#### 업적 카테고리 및 예시

| 카테고리 | 업적명 | 달성 조건 | 보상 |
|---------|--------|----------|------|
| **출석** | 철벽 출석왕 | 30일 연속 출석 | 500G + 한정 뱃지 |
| **출석** | 안전의 전설 | 100일 연속 출석 | 2000G + Legendary 뱃지 |
| **위험 신고** | 안전 파수꾼 | 위험 신고 누적 10회 | 300G + 뱃지 |
| **위험 신고** | 위험 헌터 | 위험 신고 누적 50회 (AI 검증 통과) | 1500G + Epic 뱃지 |
| **교육** | 학습의 달인 | 교육 영상 50개 완료 | 500G + 뱃지 |
| **교육** | 퀴즈 마스터 | 퀴즈 100% 정답 10회 연속 | 800G + 뱃지 |
| **장비** | 풀 세트 완성 | 5개 슬롯 모두 Epic 이상 장착 | 1000G + 특별 칭호 |
| **퀘스트** | 퀘스트 정복자 | 일일 퀘스트 전체 완료 30일 | 1000G + 뱃지 |
| **소셜** | 인기 스타 | 칭찬 누적 수신 50회 | 500G + 뱃지 |
| **전직** | 만능 전문가 | 3개 이상 전직 완료 | 2000G + Legendary 칭호 |

#### 숨겨진 업적 (히든)

사용자가 예상하지 못한 순간에 달성되어 놀라움을 선사합니다.

| 업적명 | 달성 조건 | 보상 |
|--------|----------|------|
| 새벽의 파수꾼 | 06:00 이전에 퀘스트 완료 5회 | 300G |
| 불굴의 의지 | 퀘스트 실패 후 같은 날 재도전 성공 | 200G |
| 첫 발견 | 플랫폼 가입 첫날 위험 신고 1건 | 100G |

### 3-2. 장비 세트 효과

**목표**: 장비 수집 동기 강화 및 전략적 장비 선택 유도

#### 기능 설명

같은 등급의 장비를 여러 슬롯에 장착하면 추가 보너스 효과가 발동됩니다.

#### 세트 효과 테이블

| 세트 조건 | 세트명 | 효과 |
|----------|--------|------|
| Common 장비 3개 이상 장착 | 기본 안전 세트 | 일일 퀘스트 보상 +5% |
| Rare 장비 3개 이상 장착 | 숙련자 세트 | 일일 퀘스트 보상 +10%, EXP +5% |
| Epic 장비 4개 이상 장착 | 전문가 세트 | 모든 보상 +15%, EXP +10%, 주간 보너스 골드 50G |
| Legendary 장비 5개 (풀셋) | 전설의 안전왕 | 모든 보상 +25%, EXP +20%, 전용 이펙트, 랭킹 왕관 표시 |
| 같은 색상 계열 3개 이상 | 컬러 매칭 보너스 | EXP +3% (숨겨진 세트) |

#### 구현 방향

```javascript
// src/utils/setEffectCalculator.js (신규)

export function calculateSetEffect(equippedItems) {
  const rarityCount = { common: 0, rare: 0, epic: 0, legendary: 0 };

  equippedItems.forEach(item => {
    rarityCount[item.rarity]++;
  });

  // 최상위 세트 효과만 적용 (중복 불가)
  if (rarityCount.legendary >= 5) return SET_EFFECTS.LEGENDARY_FULL;
  if (rarityCount.epic >= 4) return SET_EFFECTS.EPIC;
  if (rarityCount.rare >= 3) return SET_EFFECTS.RARE;
  if (rarityCount.common >= 3) return SET_EFFECTS.COMMON;

  return null;
}
```

**관련 기존 파일**:
- `src/utils/inventoryManager.js` — 장착 아이템 관리 (세트 효과 계산 추가)
- `src/pages/Inventory.jsx` — 세트 효과 UI 표시 (활성 세트 하이라이트)
- `src/components/EquippedGearDisplay.jsx` — 세트 이펙트 시각 효과
- `src/utils/pointsCalculator.js` — 보상 계산 시 세트 효과 반영

### 3-3. 칭찬하기 (동료 인정 시스템)

**목표**: 수평적 동기 부여 — 관리자뿐 아니라 동료로부터의 인정

#### 기능 설명

팀원의 안전 행동(퀘스트 완료, 위험 신고 등)을 보고 "칭찬" 버튼을 눌러 소량의 포인트를 전송하며, 받는 사람에게 알림이 갑니다.

#### 핵심 규칙

| 규칙 | 내용 | 이유 |
|------|------|------|
| 일일 칭찬 제한 | 1인당 하루 최대 5회 | 남용 방지 |
| 자기 칭찬 불가 | 본인에게 칭찬 불가 | 어뷰징 방지 |
| 칭찬 포인트 | 1회당 10P (발신자 부담 아님, 시스템 지급) | 부담 없는 참여 유도 |
| 칭찬 유형 | "안전 모범", "빠른 대응", "꼼꼼한 점검", "팀워크" | 구체적 인정 |
| 주간 칭찬왕 | 가장 많이 칭찬 받은 사람 주간 보상 | 선순환 유도 |

#### UI 흐름

```
[팀 피드/랭킹에서]           [칭찬 모달]                [수신자]
 동료 프로필 옆             ┌─────────────┐         ┌────────────┐
 👏 칭찬하기 버튼   →       │ 칭찬 유형 선택  │   →    │ 🎉 알림 팝업  │
                           │ ○ 안전 모범    │         │ "김안전님이   │
                           │ ○ 빠른 대응    │         │  당신을       │
                           │ ○ 꼼꼼한 점검   │         │  칭찬했습니다" │
                           │ ○ 팀워크       │         │ +10P 획득!   │
                           │              │         └────────────┘
                           │ [한줄 메시지]  │
                           │ [칭찬 보내기]  │
                           └─────────────┘
```

**신규 생성 파일**:

### 3-4. 체인 퀘스트 (연쇄 퀘스트)

**목표**: 일일 퀘스트 완수율 향상 — "하나 더"의 동기 부여

#### 기능 설명

일일 퀘스트를 일정 수 이상 완료하면 보너스 "체인 퀘스트"가 해금됩니다. 체인 퀘스트는 더 높은 보상을 제공하여 모든 퀘스트를 완료하도록 유도합니다.

```

    │
    ▼
┌─────────────────────────────────────────┐
│ 🔓 체인 퀘스트 해금!                       │
│                                         │
│ "안전 마스터 미션"                         │
│ - 오늘 수행한 안전 활동을 한 줄로 정리하세요  │
│ - 보상: 200P + 50 EXP (일반 퀘스트의 2배)   │
```

### 3-5. 장비 강화/합성 시스템

**목표**: 중복 장비의 활용처 제공 + 장기적 성장 콘텐츠

#### 기능 설명

같은 등급 장비 2개를 합성하여 상위 등급 장비를 확률적으로 획득합니다.

#### 합성 규칙

| 재료 | 결과 | 성공 확률 | 실패 시 |
|------|------|:--------:|--------|
| Common 2개 | Rare 1개 | 70% | 재료 1개 반환 |
| Rare 2개 | Epic 1개 | 40% | 재료 1개 반환 |
| Epic 2개 | Legendary 1개 | 15% | 재료 1개 반환 + 보상 토큰 1개 |
| 보상 토큰 5개 | Legendary 1개 (확정) | 100% | — |

#### 강화 시스템 (선택적 확장)

| 강화 단계 | 비용 | 효과 |
|----------|------|------|
| +1 강화 | 100G | 보너스 스탯 +2% |
| +2 강화 | 200G | 보너스 스탯 +5% |
| +3 강화 (MAX) | 500G | 보너스 스탯 +10% + 빛나는 이펙트 |

#### UI 흐름

```
[인벤토리 페이지]
    │
    ├─ [합성] 탭
```

```
                                                    ▼
                         체크리스트 자동 로드  ←    "지게차 일일 점검표"
                         - 브레이크 상태 ☐            반환
                         - 조향 장치 ☐
                         - 경적/후진경보기 ☐
                         - 포크 상태 ☐
                         - 유압 누유 ☐
                              │
                              ▼
                         점검 완료 제출     →     장비별 점검 이력
```

## 5. Phase 3 — 장기 고도화 기능

### 5-1. 위험 히트맵

현장 도면 위에 위험 신고 데이터를 열지도(heatmap)로 시각화합니다. 위험이 집중되는 구역을 한눈에 파악하여 선제적 조치가 가능합니다.

**핵심 기능**:
- 현장 도면/지도 업로드 + 좌표 매핑
- 위험 신고 건수 기반 색상 강도 표시 (녹→황→적)
- 기간별 필터 (최근 1주/1달/3달)
- 위험 유형별 필터 (추락/끼임/전기/화재)
- 클릭 시 해당 구역 신고 목록 팝업

**기술 스택**: Canvas API 또는 `react-heatmap-gl` + 도면 이미지 오버레이

---

### 5-2. AI 시나리오 시뮬레이션

Gemini AI가 생성하는 분기형 안전 시나리오입니다. 사용자의 선택에 따라 결과가 달라지며, 올바른 판단을 훈련합니다.

**예시 흐름**:
```
[상황] 비 오는 날 옥외 철골 작업 중, 동료가 안전대 없이 올라가려 합니다.

  ① "위험하니까 내려오라고 말한다" → 정답 (작업중지권 행사)
  ② "바쁘니까 빨리 하라고 한다" → 사고 발생 시나리오
  ③ "관리자에게 보고한다" → 부분 정답 (우선 제지 후 보고가 최선)
```

**보상**: 시나리오 완료 시 200P + 50 EXP, 전문항 정답 시 보너스

---

### 5-3. 실시간 알림 (WebSocket/SSE)

현재 폴링 방식에서 **Server-Sent Events(SSE)** 기반 실시간 알림으로 전환합니다.

**실시간 알림 대상 이벤트**:
- 작업중지 신고 접수 (관리자 즉시 수신)
- 팀 퀘스트 완료 임박 알림
- 칭찬 수신 알림
- 돌발 이벤트 퀘스트 생성 알림
- 시즌 종료 임박 알림

**기술**: Spring SSE (`SseEmitter`) + EventSource API (프론트엔드)

---

### 5-4. 컴플라이언스 자동 리포트

중대재해처벌법 대응을 위한 월간/분기 안전 관리 보고서를 자동 생성합니다.

**리포트 포함 내용**:
- 안전 교육 이수 현황 (법정 교육시간 충족 여부)
- 위험성 평가 실시 기록
- 작업중지권 행사 이력
- 안전 점검 체크리스트 수행 이력
- 사고/아차사고 통계

**출력 형식**: PDF 다운로드 (react-pdf 또는 서버 사이드 PDF 생성)

---

### 5-5. 다국어 지원 (i18n)

외국인 근로자 대응을 위한 다국어 인터페이스를 제공합니다.

**1차 지원 언어**: 한국어 (기본), 영어, 베트남어, 중국어 (간체)
**기술**: `react-i18next` 라이브러리
**적용 범위**: UI 라벨, 퀘스트 설명, 안전 교육 자막, 알림 메시지

```
퀘스트 완료 → questManager.completeQuest()

  └→ addSeasonPoints() (시즌 포인트 적립)
```

```
LanguageProvider (React Context)
  └→ useLanguage() hook
       ├→ t('key', params) — 번역 함수
       ├→ language — 현재 언어 코드
       └→ setLanguage(lang) — 언어 변경

지원 언어: 🇰🇷 한국어 | 🇺🇸 English | 🇻🇳 Tiếng Việt | 🇨🇳 中文
번역 키: 6개 섹션 × 37개 키 = 148개 번역 문자열
```

### 9-6. 향후 과제 (Backend 연동)

현재 Phase 1~3 전체 기능이 **프론트엔드 완전 구현** 상태이며, localStorage 모의 데이터로 동작합니다.
실제 운영 환경 적용을 위해 다음 백엔드 연동이 필요합니다:

| 기능 | 필요한 Backend 작업 |
|------|-------------------|
| 업적 시스템 | `AchievementService`, 이벤트 리스너 기반 자동 체크 |
| 팀 퀘스트 | `TeamQuestService`, 실제 팀원 데이터 연동 |
| 시즌 랭킹 | `SeasonRankingService`, 월간 리셋 스케줄러 |
| 부서 대항전 | `DepartmentBattleService`, 실제 부서 데이터 연동 |
| AI 브리핑 | `BriefingService`, Gemini API 연동 |
| QR 체크리스트 | `QRService`, 장비 QR 코드 등록/조회 API |
| 돌발 이벤트 | `EventQuestScheduler`, 외부 날씨 API 연동 |
| 위험 히트맵 | 위험 신고 좌표 데이터 연동 |
| 시나리오 | Gemini AI 동적 시나리오 생성 |
| 실시간 알림 | Spring SSE (`SseEmitter`) + EventSource API |
| 컴플라이언스 | PDF 생성 (서버 사이드), 실제 법정 데이터 연동 |
| 다국어 | 퀘스트 설명·교육 콘텐츠 다국어 DB 확장 |
| 칭찬하기 | `PraiseService`, 실제 사용자 간 칭찬 전송 |
| 장비 합성 | `ForgeService`, 서버 사이드 확률 처리 |
