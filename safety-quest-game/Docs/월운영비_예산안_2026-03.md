# 안전의 길 월 운영비 예산안

- 작성일: 2026-03-16
- 기준 프로젝트: `Life-game/safety-quest-game`
- 목적: 회사 운영비 결재용 월 예산 산정

## 1. 전제 조건

현재 운영 조건은 아래와 같이 가정한다.

- 프론트엔드 호스팅: `Vercel` 무료 플랜 사용
- 백엔드 호스팅: `Cloudtype` 사용 중이며, 무료 플랜의 `1일 1회 중지` 제약 때문에 유료 전환 필요
- 운영 DB: `Supabase` 사용 중, 현재 무료 플랜
- AI 도구: `ChatGPT Pro`, `Google AI Pro(Gemini)`, `Claude Pro/Claude Code Pro` 사용 중
- 도메인: 이미 1년 선결제 완료, 이번 월 운영비에서는 제외
- 교육 영상: `YouTube` 임베드 위주로 운영
- 사진 제보/증빙 이미지: `Supabase Storage` 또는 DB 연계 스토리지 사용량 증가 가능
- 보상 운영: `150명 x 최소 5,000원 상품권 1장`
- 인건비: 내부 인력 처리로 별도 미반영
- 예비비: 직접비 합계의 `20%`

## 2. 산정 원칙

- 본 문서는 `서비스 운영비`와 `개발 생산성용 AI 구독비`를 분리한다.
- `서비스 운영비`는 실제 서비스가 돌아가기 위해 필요한 비용만 반영한다.
- `AI 구독비`는 프로젝트 수행에 사용 중이더라도 운영 인프라와는 성격이 달라 선택 항목으로 본다.
- 달러 기반 서비스는 내부 결재 편의를 위해 `1 USD = 1,500원`으로 보수적으로 환산했다.
  - 이는 내부 예산용 가정치이며, 실제 카드 청구 금액과 차이가 날 수 있다.

## 3. 항목별 판단

### 3.1 프론트 호스팅

- `Vercel`은 현재 무료 운영 중이므로 `월 0원`으로 반영
- 현재 트래픽 규모와 구조상 우선 무료 유지가 타당

### 3.2 백엔드 호스팅

- `Cloudtype Free`는 매일 재가동이 필요하므로 실제 운영에는 부적합
- 운영 기준으로는 최소 유료 전환이 필요
- 보수적으로 아래 구성을 권장
  - 메모리 `1GB`: `11,000원/월` 추정
  - 디스크 볼륨 `10GB`: `5,500원/월`
- 권장 반영액: `16,500원/월`

### 3.3 운영 DB 및 파일 저장

- 현재 사용자 수 `150명`만 놓고 보면 `Supabase Free`의 MAU 한도는 당장 문제가 아닐 가능성이 높다
- 다만 사진 제보/증빙 이미지 저장을 고려하면 `Free`의 저장공간과 운영 안정성은 부족할 가능성이 높다
- 실제 운영 기준으로는 `Supabase Pro` 전환을 권장
- 기준 반영액: `25 USD/월 ≈ 37,500원/월`
- 이 금액으로 기본 `Pro` 조직 + 기본 프로젝트 운영을 잡고, 저장소 초과분은 예비비로 흡수하는 방식이 현실적이다

### 3.4 알림 발송

- 앱 내 알림/웹 푸시는 사실상 저비용 또는 무료로 운영 가능
- 다만 `SMS`를 붙이면 비용이 발생
- 국내 문자 단가는 소규모 구간 기준 `SMS 18원/건`, `LMS 45원/건`, `MMS 110원/건` 수준
- 본 프로젝트는 아직 대량 문자 발송 중심이 아니므로 월 예산은 `10,000원` 정도의 운영 준비비로 반영하는 것이 적절

### 3.5 교육 영상

- `YouTube` 대체 운영이므로 별도 동영상 호스팅비는 `0원`

### 3.6 사진 제보/증빙 이미지 증가분

- 초기에는 `Supabase Pro` 기본 포함량 안에서 운영 가능성이 높다
- 다만 업로드 이미지가 누적되면 스토리지와 egress가 늘 수 있다
- 월 고정 항목에 별도 큰 금액을 넣기보다 `10,000원` 수준의 저장/트래픽 완충 예산을 두는 것이 적절

### 3.7 보상 운영비

- 조건: `150명 x 5,000원`
- 월 반영액: `750,000원`
- 이 항목이 전체 운영비에서 가장 큰 비중을 차지한다

### 3.8 AI 구독비

현재 사용 중인 AI 구독은 운영비 관점에서 아래처럼 분리하는 것이 적절하다.

- `Claude Pro/Claude Code Pro`: 메인 사용 도구로 유지 권장
- `ChatGPT Pro`: 현재 사용량 대비 과투자 가능성 높음
- `Google AI Pro(Gemini)`: 보조 도구 성격이면 축소 검토 가능

실무적으로는 아래 2안 중 하나가 맞다.

- `권장안`: `Claude`만 유지하고 `GPT Pro`, `Gemini Pro`는 정리
- `확장안`: 현재 3개 구독을 모두 유지

## 6. 추천 결재안

### 추천안 A: 서비스 운영비 + Claude만 유지

- 월 예산: `약 102만원`
- 결재 반영 문구:

> 안전의 길 프로젝트의 월 운영비는 프론트/백엔드 인프라, 운영 DB, 알림 준비비, 이미지 저장 완충비, 사용자 보상비 및 예비비를 포함하여 월 988,800원으로 산정함.  
> 프로젝트 수행 도구로는 Claude 중심 운영을 적용하여 AI 구독비 30,000원을 추가 반영하며, 총 월 예산은 1,018,800원으로 책정함.

### 추천안 B: 현재 AI 구독 3종 유지

- 월 예산: `약 135만원`
- 다만 운영비 관점에서는 중복 성격이 강해 권장하지 않음

## 7. 결론

- `Cloudtype`는 무료 유지보다 유료 전환이 사실상 필요하다.
- `Supabase`는 사용자 수보다도 사진 저장과 운영 안정성 때문에 `Pro` 전환이 더 중요하다.
- 이 프로젝트의 월 비용 핵심은 인프라보다 `보상 운영비 75만원`이다.
- 회사 결재에는 `월 102만원 수준(Claude만 유지)`으로 올리는 것이 가장 합리적이다.
- `GPT Pro`와 `Gemini Pro`를 계속 유지하면 월 예산은 `약 135만원`까지 올라간다.
