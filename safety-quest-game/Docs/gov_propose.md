# 정부 아이디어 제안서 — Safety Quest

## 1. 제안 배경: "안전 수칙, 왜 알면서도 안 지킬까요?"

2024년 전체 사고 사망자 589명 중 **343명(58%)**이 추락·끼임·부딪힘 등 **기본 안전 수칙 준수만으로 예방 가능한 재래형 사고**였습니다. 작업자들은 안전 수칙을 **모르는 것이 아닙니다. 알면서도 지키지 않습니다.** 그 원인은 두 가지입니다.

**첫째, 배워도 잊습니다.** 분기 1회 집합교육(2~4시간)은 1개월 뒤 79%를 잊습니다(에빙하우스 망각곡선). 형식적인 서명만 받는 교육으로는 안전 수칙이 체화되지 않습니다.

**둘째, 스스로 하지 않습니다.** 현행 안전관리는 관리자가 위험을 찾고 지시하고, 작업자는 수동적으로 따르는 **타율적 구조**입니다. 감시가 없으면 안 지키고, "안전은 관리자 몫"이라는 인식이 고착됩니다. 규제와 처벌로는 **자발적 참여**도, **안전 습관**도 만들어지지 않습니다.

- 현장의 목소리: "서류 언제 써요?", "안전수칙 알긴 아는데, 다 지키면 일할 사람이 없어요.", "위험한 거 알지만 내 일 아니잖아요."
- 해결책: 안전 교육과 현장 위험 관리를 **매일 10분, 스마트폰으로 수행하는 게임(Quest)**으로 재설계하고, 관리자 주도의 하향식 안전관리를 **기술인(근로자)이 스스로 위험을 찾고 해결하는 자율적 구조**로 전환하는 **[게이미피케이션 기반 자율 안전관리 플랫폼 — Safety Quest]**를 제안합니다.

## 2. 아이디어 핵심: 기술인이 스스로 배우고, 찾고, 해결하는 자율 안전관리

복잡한 센서나 고가의 장비 없이, 근로자의 **스마트폰 하나**로 즉시 시작할 수 있는 **웹 기반(앱 설치 불필요)** 안전관리 플랫폼입니다.

### ① [Learn] 매일 10분 마이크로 러닝 + 간격 반복 학습

매일 아침 작업 시작 전, **10분 이내의 짧은 영상 교육 + 퀴즈 5문항**으로 안전 수칙을 학습합니다.

- **10개 교육 모듈을 5주 주기로 순환**: 같은 내용을 연간 약 10회 반복하여 **장기 기억**으로 전환 (간격 반복 학습)
- **재래형 3대 사고(추락·끼임·부딪힘)에 50% 비중**: 실제 사고 통계 기반 가중치 편성
- **학습 실효성 보장**: 영상 90% 이상 시청 필수 + 빨리감기 차단 + 퀴즈 80% 이상 통과 필수 + 미완료 시 다른 퀘스트 잠금
- **법정 교육시간 자동 관리**: 연간 약 40시간 자동 누적 (법정 4시간의 10배), 수료증 자동 발급

### ② [Find] 찾아라 위험! — 능동적 위험 인지 훈련

교육 주제와 연동된 현장 사진에서 **위험요인을 직접 찾아 터치하고 서술**합니다. "이것이 위험합니다"라고 알려주는 기존 방식 대신, **스스로 발견하는 능력**을 훈련합니다.

- 10개 모듈 × 5개 위험요인 = **총 50가지 핵심 위험 시나리오** 반복 학습
- 자기생성효과(Generation Effect): 스스로 찾고 서술한 경험은 수동적 학습 대비 **3~5배 오래 기억**

### ③ [Solve] 현장 위험요인 발견·해결 시스템 — 자율 안전관리의 핵심

기술인이 작업 중 실제 위험을 **직접 발견·등록(200P)하고 직접 해결(300P)**합니다. 등록된 위험은 **전체 대시보드에 실시간 공개**되어, 기술인·관리감독자·안전관리자 모두가 **경쟁적으로 해결**합니다.

- **기술인이 가장 높은 보상**: 직접 해결 시 300P (관리감독자 250P, 안전관리자 200P) → 자율 해결 동기 극대화
- **관리자는 감시자가 아닌 지원자**: 기술인이 해결하기 어려운 위험에 대해서만 지원
- **주간/월간 위험 해결 랭킹**: 개인·역할군·사업장 간 선의의 경쟁

### ④ [Reward] 게이미피케이션 동기부여 체계

- **15단계 레벨 시스템** (Bronze III ~ Diamond I): 장기적 성장 경로 제공
- **안전장비 아이템 수집**: 실제 보호구를 게임 속 장비로 수집·강화하며 보호구 종류와 용도를 자연스럽게 학습
- **전직(전문화) 시스템**: 유도원·신호수·밀폐담당자 등 전문 교육 이수 시 전직 → 게임 성장이 실제 전문성 향상과 직결
- **연속 출석 스트릭**: 손실 회피 심리 활용, 매일 참여 습관 형성
- **보상 공유하기**: 레벨업·위험 해결 성과를 카카오톡으로 자발적 공유 → 감시가 아닌 **자랑**으로 안전 문화 확산

### ⑤ [Stop] 작업중지권 생활화 시스템

산업안전보건법 제52조의 작업중지권을 **교육·긴급 행사 도구·보상**으로 현장에 정착시킵니다.

- **작업중지권 전용 3개 교육 모듈**: 연간 약 30회 반복 학습으로 권리 체화
- **긴급 작업중지 버튼**: 어떤 화면에서든 1터치, 30초 이내 전체 알림 전파
- **용기 포인트 500P**: 일반 위험 발견(200P)의 2.5배 → "멈추는 것이 영웅이다"

### ⑥ [Care] 날씨·계절 연동 안전 팁

기상청 API를 연동하여 매일 아침 **오늘 날씨에 맞는 맞춤형 안전 정보**를 자동 제공합니다. (비 → 미끄러짐 주의, 폭염 → 온열질환 예방, 강풍 → 고소작업 중단 검토 등)

## 3. 소규모 사업장 맞춤형 적용 방안 (현실성)

이 아이디어는 인력과 재정이 부족한 소규모 사업장에 최적화되어 있습니다.

- **비용 부담 Zero**: 고가의 CCTV·센서·VR 장비 불필요. 스마트폰만 있으면 됩니다. (연간 도입 비용 0원 vs 기존 외부 위탁 교육 120~200만원+)
- **앱 설치 불필요**: 웹 브라우저에서 바로 접속. 회원가입 후 즉시 사용 가능.
- **관리 부담 감소**: 교육 이수 기록·법정 교육시간·수료증이 모두 자동 관리. 수기 점검표 대신 사업장 안전 점수 대시보드로 안전 현황을 한눈에 파악.
- **규모 무관 적용**: 1인 사업장(사장님 혼자)부터 50인 공장(3개 역할군)까지 규모별 시나리오 제공.
- **접근성**: 게임 형태의 직관적 인터페이스로 별도 사용법 교육 불필요. 매일 10분, 작업 시작 전 완료.

## 4. 기대 효과: '규제'에서 '자율 안전관리 문화'로

- **자발적 참여 유도**: "관리자가 시켜서"가 아니라 "레벨업하고 포인트 받으려고" 즐겁게 참여 → 안전 수칙이 자연스럽게 체화.
- **기술인 주도의 안전 문화**: 관리자가 위험을 찾고 지시하는 하향식 구조에서, **기술인이 스스로 위험을 발견·해결하는 자율 안전관리 체계**로 패러다임 전환.
- **기억 정착률 향상**: 분기 1회 교육(1개월 후 기억률 21%) → 매일 10분 간격 반복(기억률 80%+).
- **위험 요인 사전 제거**: 기술인이 직접 위험을 발견하여 관리자만 볼 때보다 **발견 건수 5배+ 증가 기대**. 경쟁적 해결 구도로 신속한 위험 제거.
- **작업중지권 정착**: 반복 교육 + 시나리오 훈련 + 긴급 버튼으로, 소규모 사업장에서도 작업중지권이 실제로 행사되는 문화 조성.
- **안전 문화 정착**: 보상 공유, 랭킹 경쟁, 날씨 연동 안전 팁을 통해 소규모 사업장 내에 '안전은 내가 만드는 것'이라는 문화가 자리잡습니다.
