# 안전을 게임으로, 습관으로, 생활로 — Safety Quest

### 게이미피케이션 기반 소규모 사업장 노동안전 생활화 플랫폼

---

## 1. 한 줄 요약

> **"매일 10분, 출근길 스마트폰으로 안전 퀘스트를 수행하면 포인트와 레벨이 오릅니다. 기술인이 스스로 위험을 찾고, 스스로 해결하며, 스스로 안전을 만들어갑니다. 규제가 아닌 보상으로, 안전 수칙 준수를 일상의 습관으로 만들고, 업무 준비와 수행 중 실천을 생활화합니다."**

---

## 2. 문제 인식

### 2-1. 줄지 않는 재래형 안전사고

| 연도 | 사고 사망자 수 | 전년 대비 |
|------|:-------------:|:---------:|
| 2022년 | 644명 | — |
| 2023년 | 598명 | -46명 |
| 2024년 | 589명 | **-9명 (감소 둔화)** |

2024년 전체 사고 사망자 589명 중 **343명(58%)**이 추락·끼임·부딪힘 등 **기본 안전 수칙 준수만으로 예방 가능한 재래형 사고**입니다.

- 추락: **227명** (39%)
- 끼임: **66명** (11%)
- 부딪힘: **50명** (8%)

### 2-2. 현장의 세 가지 목소리

| # | 현장 목소리 | 핵심 문제 |
|:-:|-----------|----------|
| 1 | *"안전 교육을 제대로 하지도 않고, 이수했다는 서명만 받는 경우가 많아요."* | **형식적 교육** |
| 2 | *"지게차 작업 구간 내 출입 통제, 사다리 2인1조 같은 안전수칙을 알긴 하지만, 그거 다 지키면 일할 사람이 없어요."* | **실천 동기 부재** |
| 3 | *"안전모, 추락방지 안전벨트 등 개인보호구가 있지만 불편해서 사용하지 않아요."* | **행동 변화 실패** |

### 2-3. 근본 원인 — '아는 것'과 '하는 것'의 간극, 그리고 '타율적 관리'의 한계

작업자들은 안전 수칙을 **모르는 것이 아닙니다**. 알면서도 지키지 않습니다. 더 큰 문제는 안전이 항상 **위에서 내려오는 것**이라는 인식입니다.

```
 현행 안전관리 방식                    결과
┌──────────────┐               ┌──────────────┐
│ 분기 1회      │  ─ 한 번 듣고 → │ 다음 날 66%  │
│ 집합교육      │    잊어버림      │ 망각          │
│ (2~4시간)    │               │ (에빙하우스   │
│              │               │  망각곡선)    │
├──────────────┤               ├──────────────┤
│ 규제·벌칙 중심 │  ─ 감시 없으면 → │ 안전수칙     │
│              │    안 지킴       │ 미준수       │
├──────────────┤               ├──────────────┤
│ 관리자가      │  ─ 작업자는  →   │ 안전은       │
│ 알려주는 위험  │    수동적 수용    │ 남의 일      │
├──────────────┤               ├──────────────┤
│ 일방적 강의   │  ─ 수동적 →     │ 낮은 집중도   │
│              │    참여          │ 형식적 서명   │
└──────────────┘               └──────────────┘
```

**에빙하우스 망각곡선**에 따르면 1회 학습 후 24시간 내 66%, 1개월 후 79%를 잊습니다. 그러나 **간격 반복 학습(Spaced Repetition)**을 적용하면 같은 내용을 주기적으로 반복할 때마다 기억 유지율이 급격히 높아집니다. Safety Quest는 이 원리를 활용합니다.

그리고 무엇보다, **스스로 찾고 스스로 해결한 경험**은 누군가에게 들은 정보보다 **5배 이상 오래 기억됩니다**(자기생성효과, Generation Effect). Safety Quest는 기술인이 위험을 직접 발견하고 해결하는 주체가 되도록 설계합니다.

## 3. 제안 개요 — Safety Quest

### 3-1. 콘셉트

> **기술인이 안전의 주인공이 됩니다.**
> 스스로 배우고, 스스로 위험을 찾고, 스스로 해결합니다.
> 관리자는 감시자가 아닌 **지원자**로서, 기술인의 자율적 안전관리를 돕습니다.
> 벌칙 대신 보상으로, 의무 대신 재미로 안전을 실천하게 만듭니다.

Safety Quest는 세 가지 학술적 원리를 결합한 **웹 기반** 안전교육 플랫폼입니다.

| 원리 | 학술 근거 | Safety Quest 적용 |
|------|----------|-------------------|
| **마이크로 러닝** | 10분 이내 짧은 학습이 기억 정착률 50% 향상 (Journal of Applied Psychology) | 매일 8~10분 영상 + 퀴즈 |
| **간격 반복 학습** | 같은 주제를 5주 주기로 순환하여 장기 기억 전환 | 5주 커리큘럼 순환 (연간 약 10회 반복) |
| **게이미피케이션** | 즉각적 보상이 내적 동기를 형성 (Self-Determination Theory) | 포인트·레벨·아이템·전직 시스템 |
| **자기주도 학습** | 능동적 참여가 수동적 수용 대비 기억 정착률 3~5배 향상 (자기생성효과) | 기술인 주도의 위험 발견·해결 체계 |

### 3-2. 한눈에 보는 작동 흐름

```
 ┌─ 매일 아침 (작업 시작 전 10~15분) ──────────────────────────────────────────┐
 │                                                                             │
 │  STEP 1          STEP 2            STEP 3          STEP 4                  │
 │  출석 체크    →   오늘의 안전교육  →  찾아라 위험!  →  체크리스트             │
 │  (50P 획득)      (영상 10분        (위험 사진에서    (오늘 작업              │
 │                   + 퀴즈 5문항)     위험 5개 찾기)   안전 점검)              │
 │                  (100P 획득)       (100P 획득)      (100P 획득)             │
 │                                                                             │
 │  ──────────────── 총 약 15분, 350P 이상 획득 ──────────────────────────────  │
 └─────────────────────────────────────────────────────────────────────────────┘

 ┌─ 작업 중 · 작업 후 ─────────────────────────────────────────────────────────┐
 │                                                                             │
 │  STEP 5                     STEP 6                    STEP 7               │
 │  현장 위험요인 발견·등록  →   전체 대시보드에 노출   →   경쟁적 해결          │
 │  (기술인이 직접 발견)        (기술인·관리감독자·       (누가 먼저 해결하나?   │

 │  ──────────── 위험 발견 → 공유 → 경쟁 해결 = 자율 안전관리 사이클 ─────────  │
 └─────────────────────────────────────────────────────────────────────────────┘
```

### 3-5. 공모전 제안 방향과의 정합성

Safety Quest는 고용노동부가 제시한 **네 가지 아이디어 제안 방향**에 모두 부합합니다.

| 제안 방향 | 핵심 요구 | Safety Quest의 구체적 대응 |
|-----------|----------|--------------------------|
| **패러다임 전환 기여** | 규제 이행에서 자율적 생활 실천으로 바꾸는 아이디어 | 관리자 주도의 하향식 안전관리를 **기술인 주도의 자율적 안전관리**로 전환. 기술인이 스스로 위험을 찾고 해결하며, 관리자는 이를 **지원**하는 구조. 포인트·레벨·경쟁 보상으로 **자발적 동기**를 부여. |
| **일상 생활 속 실천** | 쉽게 배우고, 잊지 않도록 익숙하게 만드는 아이디어 | **매일 10분** 마이크로 러닝으로 배움의 부담을 최소화. **5주 순환 간격 반복**으로 1개월 후 기억률 21% → **80%+** 향상. 작업 중 위험 발견·해결까지 이어지는 **실천 중심 설계**. |
| **안전 문화 내재화** | 인식과 습관이 마음속에 깊이 새길 수 있도록 돕는 아이디어 | 기술인이 **직접 위험을 발견**하고 **직접 해결**하는 경험이 반복되면서 "안전은 내가 만드는 것"이라는 **주인의식이 내면화**. 경쟁 구도로 위험 해결이 **자랑스러운 성과**가 됨. |
| **문화적 접근** | 시각적 경고보다 인식 개선 콘텐츠, 작업자 행동 유도 중심 아이디어 | "위험합니다!" 경고 대신 "위험을 찾으면 200P!" 형태의 **긍정적 행동 유도**. 전체 역할군의 **경쟁적 해결**로 위험 제거가 게임이자 성취가 됨. |

> **핵심**: Safety Quest는 기술인을 안전관리의 **수동적 대상**에서 **능동적 주체**로 전환합니다. 관리자는 감시자가 아닌 지원자로서, 기술인의 자율적 안전관리를 뒷받침합니다.

## 4. 핵심 기능 상세

### 4-1. 매일 10분 마이크로 러닝

#### 왜 '매일 10분'인가

| 비교 항목 | 기존 집합교육 | Safety Quest |
|-----------|:----------:|:----------:|
| 빈도 | 분기 1회 | **매일** |
| 1회 소요 시간 | 2~4시간 | **8~10분** |
| 연간 총 학습 시간 | 8~16시간 | **약 40시간** |
| 1개월 후 기억률 | ~21% (에빙하우스) | **80%+** (간격 반복) |
| 참여 방식 | 일방적 강의 | 영상 + 퀴즈 + 위험찾기 |
| 법정 교육시간 충족 | 별도 관리 필요 | **자동 누적** |

#### 학습 실효성 보장 장치

단순 영상 재생이 아닙니다. 다음 4단계 검증을 모두 통과해야 교육이 완료됩니다.

```
[1단계] 시청 검증          [2단계] 빨리감기 차단
  ▸ 영상의 90% 이상         ▸ 5초 이상 앞으로 건너뛰기 시
    반드시 시청               자동 감지 → 원래 위치로 복귀
  ▸ 누적 시청 허용           ▸ "빨리감기가 감지되었습니다"
    (중간에 끊어도 이어 시청)    경고 표시

[3단계] 퀴즈 검증          [4단계] 교육 게이팅
  ▸ 5문항 객관식             ▸ 교육 미완료 시
  ▸ 80% 이상 통과 필수         다른 퀘스트 잠금 처리
  ▸ 오답 시 정답 해설 즉시     ▸ "오늘의 안전 교육을 먼저
    제공 (학습 효과 극대화)      완료해주세요" 안내
  ▸ 1일 3회 재도전 가능
```

#### 커리큘럼 — 사고 통계 기반 우선순위 편성

10개 교육 모듈을 5주 주기로 순환합니다. **재래형 3대 사고(추락·끼임·부딪힘)에 전체의 50%를 배정**하여, 실제 사고 통계에 기반한 가중치 교육을 실현합니다.

| 주차 | 요일 | 교육 모듈 | 사고 유형 | 배정 비율 |
|:----:|:----:|----------|:---------:|:---------:|
| 1주 | 월 | 사다리 작업 안전 수칙 | 추락 | |
| 1주 | 화 | 고소작업대 안전 작업 | 추락 | **추락 30%** |
| 1주 | 수 | 개구부 및 단차 추락 예방 | 추락 | |
| 2주 | 월 | 기계 작업 끼임 예방 | 끼임 | **끼임 10%** |
| 2주 | 화 | 지게차 충돌 예방 | 부딪힘 | **부딪힘 10%** |
| 3주 | 월 | 안전모 올바른 착용법 | 보호구 | |
| 3주 | 화 | 안전대 착용 및 점검 | 보호구 | **보호구 20%** |
| 4주 | 월 | 소화기 사용법 | 화재 | **화재 10%** |
| 4주 | 화 | 전기 안전 기본 | 전기 | **전기 10%** |
| 5주 | 월 | 밀폐공간 작업 안전 | 질식 | **밀폐 10%** |

> **연간 반복 효과**: 5주 × 약 10순환 = 각 모듈을 **연간 약 10회** 반복 학습하게 됩니다.
> 분기 1회 집합교육 대비 **40배의 반복 노출**이 이루어집니다.

#### 법정 교육시간 자동 관리

| 항목 | 내용 |
|------|------|
| 연간 법정 의무 | 4시간 |
| Safety Quest 연간 누적 | 약 40시간 (법정의 **10배**) |
| 관리 방식 | 모듈별 0.13~0.17시간 자동 누적 |
| 수료증 발급 | 4시간 충족 시 자동 생성 (이름·회사·이수내역·퀴즈 평균점수 포함) |

사업주가 별도로 교육 기록을 관리할 필요가 없습니다. 시스템이 자동으로 누적·산출·발급합니다.

### 4-2. 찾아라 위험! — 능동적 위험 인지 훈련

#### 왜 '직접 찾기'인가

기존 교육은 **"이것이 위험합니다"라고 알려주는 방식**입니다. 그러나 실제 현장에서는 아무도 위험을 알려주지 않습니다. 작업자 스스로 위험을 **인지하고 판단하는 능력**이 필요합니다.

Safety Quest의 '찾아라 위험!' 퀘스트는 이 능력을 훈련합니다.

#### 작동 방식

```
[1] 오늘의 교육 주제와     [2] 사진 속 위험요인을     [3] 찾은 위험이
    연동된 현장 사진 표시       터치하여 위치 지정          무엇인지 직접 서술
                                                         (5~250자)
  ┌──────────────┐       ┌──────────────┐         ┌──────────────┐
  │ 사다리 교육일  │       │    ①         │         │ "사다리가      │
  │ → 사다리 현장  │  →    │  ③   ②      │  →      │  평탄하지 않은  │
  │    사진 표시   │       │    ④  ⑤     │         │  바닥 위에      │
  │              │       │              │         │  설치되어 있음"  │
  └──────────────┘       └──────────────┘         └──────────────┘

[4] 최소 1개 ~ 최대 5개까지 찾으면 퀘스트 완료
    기본 100P + (찾은 개수 × 10P 추가)
```

#### 교육 주제별 위험요인 예시

**예시 1: 사다리 작업 안전 수칙 (1주차 월요일)**

| # | 사진 속 위험 상황 | 올바른 안전 수칙 |
|:-:|----------------|----------------|
| 1 | 울퉁불퉁한 바닥 위에 사다리 설치 | 반드시 평탄한 지면에 설치 |
| 2 | 사다리 맨 꼭대기에서 작업 중 | 최상단 2단은 밟지 않기 |
| 3 | 혼자서 사다리 작업 중 | 반드시 **2인 1조** 작업 |
| 4 | 양손에 자재를 들고 사다리 이동 | **3점 지지 원칙** (손발 중 3개 접촉) |
| 5 | A형 사다리에 전도방지대 미설치 | 아웃트리거 반드시 설치 |

**예시 2: 지게차 충돌 예방 (2주차 화요일)**

| # | 사진 속 위험 상황 | 올바른 안전 수칙 |
|:-:|----------------|----------------|
| 1 | 짐을 높이 쌓아 전방 시야 차단 | 시야 확보 후 운행 |
| 2 | 포크를 높이 들고 주행 중 | 포크 높이 지상 15~20cm 유지 |
| 3 | 지게차 포크 위에 사람 탑승 | 사람 탑승 절대 금지 |
| 4 | 작업자가 회전 반경 내에서 등 돌리고 작업 | 유도원 배치, 접근 금지 |
| 5 | 운전자 안전벨트 미착용 | 운전 시 안전벨트 필수 |

> **10개 교육 모듈 × 5개 위험요인 = 총 50가지 핵심 위험 시나리오**를 반복 학습합니다.

#### 기존 교육 대비 학습 효과 차이

| 구분 | 기존 교육 | 찾아라 위험! |

### 4-3. 현장 위험요인 발견·해결 시스템 — 자율 안전관리의 핵심

#### 왜 '기술인이 직접'인가

기존 안전관리 체계에서 위험요인 발견과 해결은 **관리자의 몫**이었습니다. 기술인(작업자)은 지시를 받아 따르는 수동적 존재였습니다. 그러나 현장의 위험을 **가장 먼저, 가장 많이** 접하는 사람은 바로 **기술인 자신**입니다.

Safety Quest는 이 점에 착안하여, **기술인이 위험의 발견자이자 해결자**가 되는 구조를 만들었습니다.

#### 작동 흐름 — 발견에서 해결까지

```

 │  ▸ 위험 유형 선택 (추락·끼임·부딪힘·전기·화재·밀폐 등)                       │

 │  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐                     │

#### 기술인 주도, 관리자 지원의 구조

| 역할 | 주요 행동 | 보상 | 핵심 역할 |
|------|----------|:----:|----------|
| **기술인** | 위험 발견·등록 (200P), 직접 해결 (300P) | **최대** | **안전의 주인공** — 발견하고, 해결한다 |
| **관리감독자** | 해결 지원 (250P), 기술인 해결이 어려운 건 직접 조치 | 중간 | **지원자** — 기술인의 자율 관리를 돕는다 |
| **안전관리자** | 전문 조치 (200P), 재발방지 대책 수립, 교육 반영 | 기본 | **전문 지원자** — 전문성이 필요한 건을 해결한다 |

> **핵심 원칙**: 기술인이 해결할 수 있는 위험은 **기술인이 직접 해결**합니다. 관리감독자와 안전관리자는 기술인이 **혼자 해결하기 어려운 위험**에 대해 지원하는 역할입니다. 이를 통해 기술인의 **자기효능감**이 높아지고, "안전은 내가 만드는 것"이라는 인식이 강화됩니다.

#### 위험요인 해결 난이도 분류

기술인이 모든 위험을 해결할 수는 없습니다. 난이도에 따라 적절한 역할이 해결합니다.

| 난이도 | 예시 | 주요 해결자 | 지원자 |
|:------:|------|:---------:|:------:|
| **기본** | 정리정돈, 보호구 미착용 시정, 경고표지 부착 | **기술인** | — |
| **보통** | 안전난간 재설치, 전선 정리, 환기 조치 | **기술인** (우선) | 관리감독자 지원 |
| **전문** | 전기 배선 수리, 구조물 보강, 밀폐공간 조치 | 안전관리자 | 관리감독자 협조 |

```
  위험 난이도별 해결 흐름

  [기본 위험]  ────→  기술인이 직접 해결 (300P)
                      "내가 할 수 있는 건 내가 한다"

  [보통 위험]  ────→  기술인이 먼저 도전 가능 (300P)
                  └→  어려우면 [지원 요청] → 관리감독자 지원 (250P)
                      "도전하되, 필요하면 도움을 받는다"

  [전문 위험]  ────→  안전관리자가 전문 조치 (200P)
                      관리감독자·기술인이 보조
                      "전문가의 도움이 필요한 건 전문가에게"
```

### 4-5. 게이미피케이션 동기부여 체계

#### (1) 레벨 시스템 — 15단계 성장 경로

| 티어 | 등급 | 누적 포인트 | 도달 예상 기간 |
|------|------|:---------:|:----------:|
| Bronze | III → II → I | 0 ~ 60,000P | 1~4개월 |
| Silver | III → II → I | 60,000 ~ 220,000P | 4~15개월 |
| Gold | III → II → I | 220,000 ~ 560,000P | 15~38개월 |
| Platinum | III → II → I | 560,000 ~ 1,180,000P | 38~79개월 |
| Diamond | III → II → I | 1,180,000P ~ | 79개월~ |

> 기술인 기준 매일 약 500P(기본) + 위험 발견·해결 보너스 → **적극적 참여 시 레벨업 가속**.
> 위험을 많이 찾고 해결할수록 빠르게 성장합니다. Diamond I은 6년 이상 꾸준히 참여해야 도달하는 "전설"입니다.

#### (2) 안전장비 아이템 — 보호구를 게임 속 장비로

포인트로 구매하는 아이템이 **실제 현장 보호구**입니다. 게임 속에서 보호구를 수집하고 강화하며, 각 장비의 종류·등급·용도를 자연스럽게 익힙니다.

| 장비 (7종) | 일반 (Common) | 고급 (Rare) | 영웅 (Epic) | 전설 (Legendary) |
|-----------|:-----:|:-----:|:-----:|:-----:|
| **안전모** | 기본 안전모 (150P) | 환기형 (500P) | 방한형 (900P) | 스마트 안전모 (2,000P) |
| **안전조끼** | 반사 조끼 (100P) | 반사띠 조끼 (400P) | LED 조끼 (800P) | — |

| **안전화** | 기본 안전화 (200P) | 미끄럼방지 (600P) | 보온 안전화 (1,100P) | 스마트 안전화 (2,500P) |
| **보안경** | 기본 보안경 (150P) | 김서림방지 (500P) | 편광 보안경 (950P) | — |

**교육적 효과**:
- *"스마트 안전모가 일반 안전모보다 왜 비싼 거지?"* → 기능 차이 학습
- *"추락방지 안전벨트는 그네식이어야 하는구나"* → 장비 스펙 이해
- *"전동 송풍식 마스크는 밀폐공간에서 쓰는 거구나"* → 용도별 보호구 선택 학습

### 4-6. 보상 공유하기 — 안전을 지켜서 받은 보상을 자랑하다

#### 왜 '보상 공유'인가

기존의 "안전 참여 현황 알림"은 작업자에게 **감시받는 느낌**을 줄 수 있습니다. 반면, 게임에서 얻은 **보상을 자랑하는 것**은 누구나 자발적으로 합니다.

Safety Quest는 이 심리를 활용합니다. 기술인이 안전 교육·퀘스트를 완료해서 받은 **보상(레벨업, 아이템, 업적, 위험 해결 성과)**을 카카오톡·문자 등으로 **자발적으로 공유**할 수 있게 합니다. 공유되는 카드에는 "안전 교육 이수로 획득"이 자연스럽게 표시되어, 가족과 동료가 **이 사람이 안전을 실천하고 있다는 것**을 자연스럽게 알게 됩니다.

#### 작동 방식

```
[1] 안전 퀘스트 완료         [2] 보상 획득 시              [3] 자발적 공유
                               "공유하기" 버튼 표시

  ┌──────────────┐         ┌──────────────┐         ┌──────────────────────┐
  │ 오늘의 안전교육 │         │  🎉 축하합니다! │         │  📱 카카오톡 공유     │
  │ ✅ 퀴즈 100점  │   →    │  Silver I 달성!│   →    │                      │
  │ ✅ 위험찾기    │         │              │         │  ┌────────────────┐  │
  │ ✅ 위험 3건   │         │ [공유하기 🔗]  │         │  │ 🏆 Silver I 달성 │  │
  │    해결!      │         │ [닫기]        │         │  │ 이번 주 위험 7건 │  │
  └──────────────┘         └──────────────┘         │  │ 발견·해결!       │  │
                                                     │  │                │  │
                                                     │  │ ─ Safety Quest │  │
                                                     │  └────────────────┘  │
                                                     └──────────────────────┘
```

> **핵심**: 자동 발송이 아닌 **기술인 본인이 누르는 공유 버튼**. 안 누르면 아무 일도 일어나지 않습니다.

#### 공유 카드 예시

| 보상 유형 | 공유 카드 내용 | 자연스럽게 전달되는 안전 메시지 |
|----------|-------------|-----------------------------|
| **레벨업** | "Silver I 달성! 안전교육 90일 연속 이수" | 가족이 "이 사람이 매일 안전교육을 하고 있구나" 인식 |
| **위험 해결** | "이번 주 위험 7건 직접 해결! 위험 사냥꾼 1위" | "현장에서 위험을 직접 찾아서 해결하고 있구나" 인식 |
| **레어 아이템** | "전설의 안전모 획득! 추락 예방 퀴즈 만점 보상" | "안전모에 대해 공부하고 있구나" 인식 |
| **전직 성공** | "밀폐공간 안전담당자로 전직! 전문 교육 이수 완료" | "전문 안전 자격을 갖추고 있구나" 인식 |

#### 기대 효과

- **자발적 공유**: 감시가 아닌 **자랑** → 부담 없이 안전 문화 확산
- **안전 정보의 자연스러운 전달**: 보상 카드에 "위험 7건 해결", "안전교육 이수" 등이 포함 → 가족·동료가 **안전 활동을 자연스럽게 인지**
- **사회적 강화**: 공유 후 가족의 "잘하고 있네!" 반응 → 안전 실천에 대한 **긍정적 피드백 루프**
- **안전 문화의 가정 확산**: 강제 알림이 아닌, 기술인이 스스로 안전을 **자랑스러운 것**으로 인식하게 됨

> **"안전을 지켜서 받은 보상이 자랑스러울 때, 안전은 의무가 아닌 자부심이 됩니다."**

### 4-7. 날씨·계절 연동 안전 팁 — 일상 속 자연스러운 안전

#### 왜 '날씨'인가

산업재해는 날씨와 밀접합니다. 비 오는 날 미끄러짐 사고, 폭염 시 온열질환, 한파 시 동상·근골격계 질환이 증가합니다. 그러나 기존 안전교육은 **계절과 무관하게 동일한 내용**을 반복합니다.

Safety Quest는 **매일 아침 현재 날씨에 맞는 안전 팁**을 자동으로 제공합니다. 경고가 아닌, 오늘 하루를 위한 **맞춤형 안전 정보**입니다.

#### 작동 방식

```
  기상청 API             Safety Quest              작업자 화면
┌──────────────┐     ┌──────────────┐       ┌──────────────────────┐
│ 오늘 날씨:    │     │ 날씨 조건 →   │       │ 🌧️ 오늘의 안전 팁    │
│ 비, 15°C     │ →   │ 안전 팁 매핑   │  →    │                      │
│ 강수량 20mm  │     │              │       │ "비 오는 날입니다.     │
│              │     │              │       │  미끄럼방지 안전화를   │
└──────────────┘     └──────────────┘       │  꼭 착용하세요!"      │
                                            └──────────────────────┘
```

#### 날씨별 안전 팁 예시

| 날씨 조건 | 안전 팁 | 관련 위험 |
|----------|---------|----------|
| 🌧️ **비** | "미끄럼방지 안전화 착용, 작업장 바닥 물기 제거" | 미끄러짐·추락 |
| 🌨️ **눈/한파** | "보온 장갑 착용, 철골 구조물 결빙 주의" | 동상·미끄러짐 |
| 🌡️ **폭염** (33°C↑) | "매 시간 10분 그늘 휴식, 물 충분히 섭취" | 온열질환 |
| 💨 **강풍** (10m/s↑) | "고소작업 중단 검토, 가설구조물 고정 확인" | 추락·낙하물 |
| 🌫️ **안개/황사** | "방진마스크 착용, 시야 확보 후 중장비 운행" | 충돌·호흡기 |

#### 기대 효과

- **일상 생활 속 실천**: 매일 아침 날씨와 함께 안전 정보를 자연스럽게 접함
- **맞춤형 정보**: "오늘 나에게 필요한" 안전 팁 → 실천 가능성 극대화
- **문화적 접근**: 경고가 아닌 "오늘의 날씨 안전 팁"이라는 친근한 형태

### 4-8. 사업장 안전 점수 대시보드 — 자율 안전관리의 성과 시각화

#### 왜 '안전 점수'인가

소규모 사업장 사업주는 "우리 사업장의 안전 수준이 어느 정도인지" 객관적으로 파악하기 어렵습니다. Safety Quest에 축적된 데이터를 종합하여 **0~100점 사이의 안전 점수**를 제공합니다. 특히 **기술인의 자율적 안전 활동**이 점수에 가장 큰 비중을 차지하여, 기술인 주도의 안전관리가 사업장 전체의 성과로 이어지는 구조입니다.

#### 안전 점수 산출 기준

| 항목 | 배점 | 측정 방법 |
|------|:----:|----------|
| 교육 이수율 | **25점** | 전 작업자 일일 교육 완료 비율 |
| 퀴즈 평균 점수 | **15점** | 전 작업자 퀴즈 평균 (80점 이상 시 만점) |
| **위험 발견 건수** | **25점** | 기술인의 자율적 위험 발견·등록 건수 |
| **위험 해결률** | **20점** | 발견된 위험 대비 해결 완료 비율 |
| 체크리스트 작성률 | **10점** | 일일 안전 체크리스트 작성 비율 |
| 연속 참여율 | **5점** | 월간 출석 마일스톤 달성률 |
| **합계** | **100점** | |

> **위험 발견(25점) + 위험 해결률(20점) = 45점**으로 전체의 거의 절반. 기술인이 스스로 위험을 찾고 해결하는 활동이 사업장 안전 점수의 핵심입니다.

#### 활용 예시

```
┌───────────────────────────────────────────────────────┐

│                                                       │
│  📚 교육 이수율     23/25  ████████████████████▒▒  92% │
│  📝 퀴즈 평균       13/15  ██████████████████░░░░  87% │
│  🔍 위험 발견       21/25  ████████████████████░░  84% │
│  ✅ 위험 해결률     17/20  ██████████████████░░░░  85% │
│  📋 체크리스트      8/10   ████████████████░░░░░░  80% │
│  🔥 연속 참여율     4/5    ████████████████░░░░░░  80% │
│                                                       │
│  📈 지난주 대비 +5점 상승                               │
│  🏆 김기술님 이번 주 위험 7건 발견·해결 → MVP!           │
│  💡 "기술인들의 위험 발견이 활발합니다! 해결률을           │

└───────────────────────────────────────────────────────┘

#### 기대 효과

- **기술인 성과 가시화**: 기술인의 자율적 안전 활동이 사업장 점수에 **직접 반영**
- **사업주 참여 유도**: 숫자로 보이는 안전 수준 → "기술인들이 잘하고 있구나" 인식
- **객관적 안전 현황**: 감(感)이 아닌 **데이터 기반 의사결정**
- **선순환 구조**: 기술인의 활약 → 사업장 점수 상승 → 사업주 지원 강화 → 기술인 동기 상승

## 5. 소규모 사업장 적용성

### 5-2. 사업장 규모별 도입 시나리오

#### 시나리오 A: 1~5인 인테리어 시공업체

> 사장님 혼자 또는 2~3명의 기술인이 있는 소규모 현장

- **아침 출근 시**: 사장님과 기술인 모두 스마트폰으로 10분 교육
- **작업 중**: 기술인이 **직접 위험 발견·등록** → 사장님 대시보드에 표시
- **기술인 자율 해결**: 기본·보통 난이도 위험은 **기술인이 직접 해결**
- **효과**: 1인 사업장에서도 **기술인 스스로 안전을 관리**. 법정 교육시간 자동 충족.

#### 시나리오 B: 10~20인 건설 현장

> 현장소장 1명 + 기술인 10~15명의 중소 현장

- **기술인**: 매일 10분 교육 + **현장 위험 발견·등록** + 직접 해결
- **현장소장**: 기술인이 지원 요청한 건에 대해 **해결 지원** (관리감독자 역할)
- **경쟁 구도**: 기술인 간 위험 발견·해결 **랭킹 경쟁** → 안전 참여 활성화
- **효과**: 기술인이 **안전의 주인공**, 현장소장은 **지원자**. 자율 안전관리 문화 형성.

#### 시나리오 C: 30~50인 제조 공장

> 안전관리자 1명 + 관리감독자 2~3명 + 기술인 30명

- **기술인**: 위험 발견·등록·직접 해결이 핵심 활동
- **관리감독자**: 기술인이 지원 요청한 위험에 대해 **해결 지원**
- **안전관리자**: 전문적 위험에 대한 **전문 조치 + 재발방지 대책**
- **3개 역할 경쟁**: 위험 해결 랭킹에서 기술인·관리감독자·안전관리자 **선의의 경쟁**
- **효과**: 기술인 주도의 자율 안전관리 + 경쟁 구도로 **위험 해결률 극대화**

## 6. 기대 효과 및 측정 지표

### 6-1. 핵심 성과 지표 (KPI)

| 구분 | 지표 | 목표치 | 측정 방법 |
|------|------|:-----:|----------|
| **참여** | 일일 교육 이수율 | 100% | 교육 미완료 시 퀘스트 잠금 (게이팅) |
| **참여** | 일일 활성 사용률 | 80%+ | 스트릭 데이터 기반 |
| **학습** | 퀴즈 평균 점수 | 85%+ | 5문항 × 10모듈 자동 채점 |
| **자율 발견** | 기술인 위험 발견 건수 | 일 2건+/인 | 위험 등록 데이터 |
| **자율 해결** | 기술인 직접 해결률 | 60%+ | 발견 대비 기술인 해결 비율 |
| **경쟁** | 위험 해결 참여율 | 80%+ | 전체 역할군 해결 참여 비율 |
| **실천** | 전체 위험 해결률 | 90%+ | 발견 대비 해결 완료 비율 |
| **법정** | 연간 교육시간 | 40시간+ | 자동 누적 (법정 4시간의 10배) |
| **지속** | 월간 유지율 | 70%+ | 월간 출석 마일스톤 달성률 |

### 6-2. 기대 효과 — 세 가지 차원

#### 1차 효과: 기술인의 자율적 행동 변화

| 변화 전 | 변화 후 | 동인 |
|--------|--------|------|
| "안전교육? 서명만 하면 되지" | 매일 10분 **자발적 참여** | 포인트·레벨 보상 |
| "안전수칙? 알긴 아는데..." | 매일 반복으로 **체화된 습관** | 간격 반복 학습 |
| "위험? 누군가 알려주겠지" | **내가 직접 찾고 해결**한다 | 위험 발견·해결 보상 + 경쟁 |
| "보호구? 불편해서 안 써" | 게임 아이템으로 **친숙함 형성** | 수집·강화 동기 |
| "안전은 관리자 몫이지" | **안전은 내가 만드는 것** | 자기주도 + 성취감 |

#### 2차 효과: 조직 문화 변화

- **기술인 주도의 안전 문화**: "위에서 시켜서"가 아닌 "**내가 알아서**" 하는 문화
- **관리자의 역할 전환**: 감시자에서 **지원자**로 → 기술인과의 신뢰 관계 강화
- **경쟁을 통한 협력**: 위험 해결 경쟁이 결과적으로 **사업장 전체의 안전 수준 향상**으로 연결
- **데이터 기반 의사결정**: 축적된 위험 발견·해결 데이터로 **객관적 안전 현황 파악**

#### 3차 효과: 사고 예방 기여

- 기술인이 **직접 위험을 발견**하므로 → 관리자만 볼 때보다 **발견 건수 5배+ 증가 기대**
- **경쟁적 해결 구도**로 → 발견된 위험의 **신속한 해결** (평균 해결 시간 단축)
- 매일 **50가지 핵심 위험 시나리오** 반복 훈련 → 위험 인지 능력 향상
- **체크리스트 일일 작성** → 작업 전 위험요소 사전 확인 습관화

고용노동부 '노동안전 종합대책'(2025.9)은 **'규제하고 벌칙을 주는 방식'에서 벗어나, 사업주와 노동자 모두가 안전을 '생활 속의 습관'으로 자연스럽게 받아들이고 실천할 수 있도록 패러다임을 전환**해야 할 시점이라고 명시하고 있습니다.

Safety Quest는 이 전환을 실현하는 **구체적이고 즉시 적용 가능한 도구**입니다. 특히, **기술인이 안전의 주체가 되는 자율적 안전관리 체계**를 통해 진정한 패러다임 전환을 이룹니다.

| 현장의 목소리 | Safety Quest의 답 |
