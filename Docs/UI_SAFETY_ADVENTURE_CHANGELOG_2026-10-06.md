# 안전 모험 UI 개편 · 2026-10-06

‘안전을 게임으로. 오늘의 현장이, 나의 성장으로.’를 중심으로 화면을 개편했습니다.

- 크림 바탕·흰 카드·인디고 행동 버튼으로 공통 스타일을 정리했습니다.
- 홈에서 역할 캐릭터, 레벨·XP, 가상 장비, 오늘의 퀘스트 경로와 다음 도전을 보여줍니다.
- 교육 전 잠금, 진행 가능, 완료 상태와 실제 보상을 표시합니다.
- 위험 발견·현장 시나리오 진입을 강조하고 추가 도전을 펼침 영역으로 정리했습니다.
- 프로필·로그인·회원가입·보상안내를 같은 디자인 체계로 연결했습니다.
- 임의의 참여자 수, 점수, 순위, 날씨, 보상 내역을 제거했습니다.

기존 인증·권한, 교육 이수 판정, 보상 계산과 베타 종료 운영 방식은 유지합니다. 이번 커밋에는 UI 수정 전부터 작업 중이던 별도의 서버 연동 변경을 포함하지 않습니다.

## 확인

제품 빌드·PWA 생성, 데스크톱·모바일 배치, 세 역할과 퀘스트의 잠금·진행·완료·빈 상태, 베타 종료 메뉴를 확인했습니다. 실제 계정의 서버 연동은 검증하지 않았습니다.

`safety-quest-game/scripts/ui-review.html`은 개발용 예시 화면입니다. 예시 데이터는 메모리에서만 사용하며 제품 빌드에 포함되지 않습니다.
공통 디자인 기준은 `safety-quest-game/Docs/UI_DESIGN_SYSTEM.md`입니다.

## 수정 전 상태

수정 전 파일은 프로젝트 밖의 로컬 백업에 보관했습니다. 원본 해시와 이번 변경 목록을 기준으로 별도 사본에서 복원을 확인했습니다. 이후 변경과 관련 없는 파일을 보호하도록 복원 도구를 구성했습니다. 로컬 설정이 포함된 원본 백업은 이 저장소에 올리지 않습니다.
